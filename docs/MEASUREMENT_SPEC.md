# 参数测量与损耗口径

本文记录 DPT 项目的参数定义、损耗窗口、Trr/Err 口径和单/双脉冲处理原则。涉及具体样例数值和验证要求时，还必须阅读 `REGRESSION_BASELINES.md`。

## 偏移测量定义

偏移测量的定义必须以泰克官网资料为准，不允许凭印象补定义。

当前依据：

- Tektronix `4, 5, 6 Series MSO Programmer Manual`
- Part Number `077189803`
- Release Date `2026-03-11`
- `MEASUrement:ADDMEAS` 测量类型说明
- https://www.tek.com/en/manual/oscilloscope/4-5-6-series-mso-programmer-manual-5-series-mso-low-profile
- PDF: https://download.tek.com/manual/4-5-6-Series-MSO_Programmer_077189803.pdf
- Tektronix TBS2000 自动测量教学页：RMS/Mean/Area 定义说明
- https://www.tek.com/en/video/how-to/how-to-make-rms-mean-and-area-measurements-using-automatic-functions-on-a-tbs2000-oscilloscope

按该资料，偏移测量含义为：

- `Maximum` 是选定范围内最大数据点。
- `Minimum` 是选定范围内最小数据点。
- `Peak-to-Peak` 是 `Maximum - Minimum`。
- `Mean` 是数据点算术平均值。
- `RMS` 是数据点真均方根。
- `AC RMS` 是相对于 `Mean` 的真均方根。
- `Area` 是对数据点积分，0 轴以上面积为正、0 轴以下面积为负。
- `Top` 是波形中点以上最常见的数据值。
- `Base` 是波形中点以下最常见的数据值。
- `Amplitude` 是 `Top` 与 `Base` 的差值。
- `Positive Overshoot` 是 `(Maximum - Top) / Amplitude * 100%`。
- `Negative Overshoot` 是 `(Base - Minimum) / Amplitude * 100%`。

`全波形`、`屏幕`、`光标` 只改变取样时间范围，不改变上述定义。

若实现中用分位数等轻量方法近似 `Top/Base` 的“最常见值”，必须在代码/说明中称为近似，不能宣称完全复刻泰克 histogram 算法，除非已按官方算法实现并用可信样例验证。

## Eoff 口径

- `Ha` 是 Vce 抬升前导通平台。
- `A` 是 Vce 主上升沿穿 `Ha` 的真实交点。
- `Hb` 是带符号 Ic 回落平台。
- `B` 是本次关断过程中 Ic 经过主下降后、局部可见阻尼振荡首次达到低幅稳定标准时与 `Hb` 的真实交点。
- 积分用原始 `Vce * Ic`。
- 不得使用主沿前噪声穿越、第一次刚碰平台就截断、稳定后的长尾小噪声/后续 LC 尾巴、最后显著拖尾或段界点作为 A/B。
- Eoff 右侧 B 只能看关断过程 `Ic` 主下降沿与关断本地 `Hb(Ic)` 的回落交点。

## Eon 口径

- `Ha` 是带符号 Ic 抬升前平台。
- `A` 是 Ic 主上升沿穿 `Ha` 的真实交点。
- `Hb` 是 Vce 回落后导通平台。
- `B` 是本次开通过程中 Vce 经过主下降后、局部可见阻尼振荡首次达到低幅稳定标准时与 `Hb` 的真实交点。
- 积分用原始 `Vce * Ic`。
- `Hb(Vce)` 不得因为手动拖动竖向光标后的联动显示值而重标定，平台线仍按自动平台算法取值。
- 不得使用主沿前噪声穿越、第一次刚碰平台就截断、稳定后的长尾小噪声/后续 LC 尾巴、最后显著拖尾或段界点作为 A/B。
- Eon 右侧 B 只能看开通过程 `Vce` 主下降沿与开通本地 `Hb(Vce)` 的回落交点。

## Err 口径

- `Ha` 是 IRM 主峰后主要大振荡结束、进入本次恢复过程稳定区后的 Irr base 有效值。
- `Ha` 取首次达到低幅稳定标准的本地稳定窗内 `(max+min)/2`。
- `A` 是这条 `Ha` 横线与 Irr 曲线在稳定区入口附近的真实交点。
- 积分也必须使用同一个 A，不得用拟合点或旧首个下降点代替。
- `Hb` 是第二脉冲开通过程/反向恢复段内，对管电压 Vd 主上升沿前的本地 base，不是全局 base，也不是第一脉冲关断过程 base。
- `B` 唯一口径是同一段 Vd 曲线与 `Hb` 横线在主上升沿上的真实插值交点。
- 积分窗口取 A/B 之间，积分用 `abs(Vd) * abs(Irr)`。
- 不得再使用主沿前 0V 附近噪声上穿点、主峰前最后一次上穿点、固定 `400~800ns` 尾窗、拟合点、段界点、最后更小尾窗或旧兼容分支作为 A/B。
- Err 的“从 IRM 尖峰往后第一个达到低幅稳定标准”只适用于反向恢复电流 `Irr` 的 A/Ha。
- Err 的 Vd-B 仍必须是第二脉冲开通过程/反向恢复段内 Vd 曲线与本地 `Hb(Vd)` 横线的真实交点。

## 损耗卡尺统一专业口径

- Eoff/Eon/Err 损耗卡尺左侧起点按对应主沿进入有效重叠区确定。
- 右侧终点必须考虑本次开关过程右侧的有效阻尼振荡，落到“本地平台横线与对应波形曲线”的真实插值交点。
- 三类损耗的右侧判定不能混用。
- 右侧震荡是否结束必须看本过程对应波形在本地窗口内的最大值、最小值及峰峰值。
- 严重振荡工况下，平缓区的 `max-min` 必须明显缩小后才能落右侧竖向光标。
- 必要时可对判定用波形做短窗平滑以排除采样毛刺，但最终 A/B 光标仍必须落在原始波形与横向平台线的真实插值交点。
- 不要保留“第一次刚碰平台就截断”“贴近旧交点则沿用”“固定尾窗”“最后显著拖尾”“hold 均值防抖后返回原始小穿越”“B 太近就跳到固定时间点”等旧分支。
- 不要为了追求更晚光标把稳定平台之后的长尾无限纳入积分。
- 当前实现按损耗类型分别锚定对应波形的对应主沿，再在本过程窗口内用本地平台和有效振荡幅度选择右侧真实交点；光标落点和积分窗口必须使用同一个时间点。

## Trr 口径

- Trr 自动结果、默认光标落点、手动拖动后的重算必须共用 `metrics/irr_measure.py` 的同一套核心逻辑。
- `Ha` 为本次反向恢复过程参考电流线。
- `A` 是 Irr 进入主恢复瓣时第一次与 `Ha` 相交的真实插值点。
- `B` 是 Irr 主峰之后第一次回落到 `Ha` 的真实插值点。
- Trr 只统计主恢复时间，不能因为 Err 能量窗口需要有效尾段就把 Trr 的 B 拖到后续衰减振荡结束。
- 不得恢复 `reverse_recovery_trr()` 的固定 `5A` 近零阈值、GUI 默认区间的前窗 `mid` 口径，或任何自动表格/默认卡尺/手动卡尺各算一套的分支。

## 双脉冲原则

- 双脉冲文件必须识别为双脉冲时，关断取第 1 脉冲，开通/反向恢复取第 2 脉冲。
- 不能退化成单脉冲，也不能把开通窗落到错误平台。

## 单脉冲原则

- 单脉冲 TSS 数据只有关断过程，不包含有效的第二脉冲开通、反向恢复、Eon、Err 或开通 di/dt。
- 遇到单脉冲样例时，算法和验证脚本必须进入单脉冲/仅关断口径。
- 只提取并验证 Vdc、Idc、关断 `Delta Vce`、关断 `dv/dt`、关断 `di/dt`、`Ls_off`、`td_off/tf/toff`、Eoff、关断串扰等关断参数。
- 不要把缺失的第二脉冲当成算法失败。
- 不要为了凑 Eon/Err 人为构造开通窗。

## 开通电流、开通 di/dt 与 Ls_on

- 开通电流/开通 di/dt 的 `Ha` 必须共用同一套 Ic 抬升后平台逻辑并保持一致。
- 开通 `Delta Vce`/`Ls_on` 的下点是 Vce 主下降过程中的拐点/平台点。
- 若 Vce 在主下降前先跌落到一个可见且持续的短稳定平台，开通 `Delta Vce`/`Ls_on` 的下点优先取该平台内最平稳小窗的 `(max+min)/2`，而不是继续落到后续主下降段。
- 不允许把开通 `Delta Vce`/`Ls_on` 的下点改成全段最小值或损耗窗口点。

## 短路 Tsc 口径

- 短路时间 `Tsc` 默认取值范围命名为 `0%-0%`，对应短路电流相对基线 `Hb` 的上升沿/下降沿交点。
- `10%-10%` 取值范围以短路电流最大幅值为 100%，用上升沿 10% 与下降沿 10% 作为计算阈值，A/B 纵向光标卡在对应电流曲线与阈值的真实交点。
- 修改 `Tsc` 取值范围只改变短路时间的 A/B 光标和 `Tsc` 数值；短路能量窗口不得因此被联动缩窄，也不得新增额外虚线辅助标记。
