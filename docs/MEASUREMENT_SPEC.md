# 参数测量与损耗口径

本文记录 DPT 项目的参数定义、损耗窗口、Trr/Err 口径和单/双脉冲处理原则。涉及具体样例数值和验证要求时，还必须阅读 `REGRESSION_BASELINES.md`。

完整流程规范：

- 双脉冲 DPT 计算逻辑见 `DOUBLE_PULSE_SPEC.md`。
- 偏移测量计算逻辑见 `OFFSET_MEASUREMENT_SPEC.md`。
- Tektronix 示波器式测量词典、`Top/Base`、参考电平、RMS/AC RMS、Area、时间/频率/脉宽、WBG-DPT 测量项、测量范围和本地窗口通用定义见 `TEKTRONIX_MEASUREMENT_DEFINITIONS.md`。

## 偏移测量定义

偏移测量、横向平台线、斜率参考电平和示波器式统计项的定义必须以泰克官网资料和 `TEKTRONIX_MEASUREMENT_DEFINITIONS.md` 为准，不允许凭印象补定义。

当前依据：

- Tektronix `4, 5, 6 Series MSO Programmer Manual`
- Part Number `077189803`
- Release Date `2026-03-11`
- `MEASUrement:ADDMEAS` 测量类型说明
- https://www.tek.com/en/manual/oscilloscope/4-5-6-series-mso-programmer-manual-5-series-mso-low-profile
- PDF: https://download.tek.com/manual/4-5-6-Series-MSO_Programmer_077189803.pdf
- Tektronix TBS2000 自动测量教学页：RMS/Mean/Area 定义说明
- https://www.tek.com/en/video/how-to/how-to-make-rms-mean-and-area-measurements-using-automatic-functions-on-a-tbs2000-oscilloscope

按该资料，偏移测量含义为：

- `Maximum` 是选定范围内最大数据点。
- `Minimum` 是选定范围内最小数据点。
- `Peak-to-Peak` 是 `Maximum - Minimum`。
- `Mean` 是数据点算术平均值。
- `RMS` 是数据点真均方根。
- `AC RMS` 是相对于 `Mean` 的真均方根。
- `Area` 是对数据点积分，0 轴以上面积为正、0 轴以下面积为负。
- `Top` 是波形中点以上最常见的数据值。
- `Base` 是波形中点以下最常见的数据值。
- `Amplitude` 是 `Top` 与 `Base` 的差值。
- `Positive Overshoot` 是 `(Maximum - Top) / Amplitude * 100%`。
- `Negative Overshoot` 是 `(Base - Minimum) / Amplitude * 100%`。

`全波形`、`屏幕`、`光标` 只改变取样时间范围，不改变上述定义。

所有上述测量项必须先确定取样范围，再在该范围内计算。局部放大窗口、偏移测量屏幕范围、参数本地窗口和用户手动 A/B 范围不能混用全波形 `Top/Base` 或旧缓存值。

若实现中用分位数等轻量方法近似 `Top/Base` 的“最常见值”，必须在代码/说明中称为近似，不能宣称完全复刻泰克 histogram 算法，除非已按官方算法实现并用可信样例验证。

## 参数卡光标与波形归属

- 每张参数卡必须声明 A、B、Ha、Hb（适用时含 H0）的逻辑波形角色。表格值、默认光标、交点圆点、顶部读数、状态栏和报告截图必须复用同一角色与同一测量上下文；数值接近但光标落在另一通道、另一事件或无关噪声上仍判为失败。
- A/B 是语义端点，不是“当前选中通道”的两个普通时间点。跨通道 IEC 时序必须保持各自物理源，例如 Toff/Td_off 的 A=Vge、B=Ic；Err 即使物理上 B 位于 A 左侧，也必须保持 A=Irr、B=Vd。不得为了按时间排序而交换字母或通道。
- Ha/Hb 必须绑定本参数声明的横向波形。切换参数、进入不可用参数、单击/双击高亮其他通道或恢复手动状态时，旧绑定必须被原子替换或清除，不能残留上一张卡的横线、单位、读数或标记。
- 每次点击新的参数卡都必须先清除旧 `_active_slope_param` 及其回调/卡尺上下文；只有当前 `dv/dt`/`di/dt` 卡已确认可用并成功建立斜率上下文后才允许重新设置。非斜率卡、不可用卡、单脉冲缺失项或无合法区间的卡都必须保持清空，后续重算不得复活上一张斜率卡。
- 自动状态下，交点圆点必须落在对应原始/派生逻辑波形的真实交点。用户手动解耦 A/B 与 Ha/Hb 后，圆点仍采样当前 A/B 时刻的语义端点波形，用于辨认端点属于哪条曲线；不得继续画在旧 Ha/Hb 电平而悬空，也不得改绑当前高亮通道。
- 功率卡的数值始终按权威原始 V×I 计算。有且仅有可信 W/kW Math 轨迹与原始功率形状/幅值匹配时，该轨迹可以同时拥有 A/B/Ha 显示；候选变化或失配时必须原子重绑 A/B、Ha/Hb、活动轴和辅助点。没有可信功率轨迹时，A/B 回到该损耗卡的原始 V/I 边界波形，Ha/Hb 隐藏且清除旧功率标记。
- `Pmax/Eon/反向恢复 Pdmax` 从手动窗口恢复、重新点击或由其他参数切回时，可见 Math 仍只恢复显示坐标；结果对象、参数表、状态栏值与报告值必须按相应原始 `Vce*Ic` 或 `abs(Vd)*abs(Irr)` 重新确认，禁止把缩放后的 Math 峰值/积分写回权威值。
- `Irr` 的默认 A 取主换流沿前最近的完整合格稳定带代表点，不能受已经进入上升沿的 `reverse_recovery[0]` 截断；B 取峰后振荡收敛的首个完整合格稳定带代表点，搜索不越过下一次关断。两端以完整 `200ns` 带证明稳定，并校验局部噪声、平台偏差及后续反弹；200ns 是证据带宽，不是固定显示窗或左侧留白。`di/dt` 的前态参考只作为经 Irr 原始事前平台校验后的提示，不得把恢复主瓣电平误作 Irr 事前平台。此校验只选择显示时刻，不改 `di/dt` 上下文、Irr 峰值、Ha/Hb、Trr/Err 或手调状态。
- 对显式 `max/peak` 参数，默认竖向 A/B 与横向 Ha/Hb 分工：A/B 表达本参数从事前稳定平台、经过主沿/权威峰值、到事后稳定平台的完整物理取值阶段；Ha 保留提取链已经发布的权威带符号峰值，Hb 显示本参数定义的稳定参考平台。初次点击或重新计算后的默认展示不得用较宽 A/B 重新搜索峰值，也不得用峰值窄窗反向缩短稳定平台范围；只有用户真正拖动 A/B 并在释放时提交手动范围后，才按既有手动极值规则重算并保存。
- 相关卡的默认角色固定为：关断 `Vce_off_max` 为 `Vce Base→Top / Ha=峰值、Hb=Top`，关断 `Ic_off_max` 为 `Vce Base→Ic Base / Ha=Ic峰值、Hb=Ic Base`，开通 `Vce_on_max` 为 `Vce Top→Base / Ha=既有权威最大值、Hb=Vce Base`，开通 `Ic_on_max` 为 `Ic Base→Ic Top / Ha=Ic峰值、Hb=Ic Base`，反向恢复 `Vrr` 为 `Vd Base→Top / Ha=Vrr峰值、Hb=Vd Top`，`Irr` 为 `前向稳定平台→恢复Base / Ha=恢复Base、Hb=有符号I_RM峰值`。其中 `Ic_off_max` 的 A 取 Vce 抬升前 Base 稳定段代表点，B 取同一次关断 Ic 主抬升前的稳定 Base 段（`di/dt` 上下文 `base_window`）内最接近该 Base 电平的代表点（2026-10-16 用户拍板「甲 · 稳定抬升前 Base」，与 accepted `turn-off-delta-vce-stable-range-cursors-v24` 一致；不得改为「Ic 主下降结束后向右搜索的首个完整 200ns 稳定带中心」，该写法在本项目低电流语料上多处无解）；`Ic_on_max` 的 A/B 均绑定 Ic，A 取 Ic 抬升前 Base 稳定带的最晚合格代表点，B 取抬升后电流振荡收敛的最早合格 Top 稳定带代表点。关断 `Hb` 仍沿用提取层已发布的带符号 Ic Base，开通 `Hb` 保留本次修正前的带符号 Ic Base 参考；两者均不能由 B 单点或显示稳定带重算。各卡上升沿/下降沿方向不同，但都不得让辅助 Vge 或当前高亮通道拥有 A/B。
- `Vce_on_max` 的竖向细化规则：A 取既有权威最大值左侧的相邻 Top 稳定段代表点，必须严格位于该峰值之前；B 在主下降后从左到右寻找首个完整 `200ns` 合格 Base 稳定带并取中心，不能把下降尾段或孤立的 Base 交点当作稳定平台，也不得越过下一次关断。保证峰值包含和平台精度后尽量缩短 A/B 间距；不为缩短范围排除早于主下降沿的真实最大值。仅这张卡拥有该独立默认时间上下文，`ΔVce`、提取峰值窗、原有 Ha/Hb 和手动覆盖不变；稳定带宽不等于局部视窗宽度，更不是固定左侧 `0.4us`。
- `Vrr` 默认 A 取 Vd 主抬升前最近的完整合格 Base 带中心，B 取权威峰值之后振荡收敛的首个完整合格 Top 带中心。开通段起点已在上升沿时允许使用相邻事件前史，但不越过前次关断；后态搜索止于下次关断前。两端均须有完整 `200ns` 稳定带、有限采样值、平台偏差/漂移和后续反弹检查，不得以“评分最低但不合格”的振荡带或单个近电平点冒充平台。这里只选择默认显示时刻，既有 Base/Top 电平、Vrr 峰值、Ha/Hb、dv/dt、Trr/Err 和用户手调状态不变。
  - 同一电压采样量程下，Vrr 后态候选的噪声容差还须受事前安静带约束；不能由整个持续振荡尾段反向放宽容差，导致周期振荡被判成稳定 Top。该约束仅由 Vrr 调用启用，Irr 的既有噪声处理保持不变。
- 非门极参数的局部显示窗在容纳真实 A/B、稳定平台和主事件的前提下，将同档位剩余余量约按左 `30%`、右 `70%` 分配；开通 `dv/dt`、`di/dt` 和与开通 `di/dt` 共用 A/B 积分窗的 `Ls_on`，在硬内容允许时改用真实 A/B 中点约 `43%` 的平衡构图，以同时观察 Base/Top 稳定电压或电流平台。比例只是自适应构图偏好。通常以 `2us` 为软基准，`Ic_off_max` 单项以 `2.5us` 为软基准；两者都不是计算窗、硬性最小值或固定裁切宽度。左侧前态由当前波形实际稳定带动态决定，`0.4us` 只是一张样例的观察说明。

## 手动校准与报告写入

- 用户释放 A/B、Ha/Hb（适用时含 H0）后提交的参数值是当前 `ExtractResult` 的权威人工覆盖，不能只留在绘图对象或参数卡缓存中。点击“写入报告”时必须冻结当前文件、测试模式、`off/on` 脉冲对、已物化人工结果、各参数光标和各参数精确局部 X 轴页面；参数表、Excel 单元格和报告截图必须使用同一快照。
- 当前选中脉冲对的人工值必须覆盖该组合的默认自动值；后台只允许为其他未手调脉冲组合重新提取。任何报告准备、截图回放或 writer 阶段都不得用默认提取结果覆盖当前组合，也不得把 Math 显示缩放值写回权威参数。
- 若人工状态与当前文件、测试模式或脉冲对的所有权不匹配，必须拒绝写入而不是静默降级到默认结果；报告截图恢复光标与局部视图不能作为 Excel 数值错误后的补救机制。

## Eoff 口径

- `Ha` 是 Vce 抬升前导通平台。
- `Hb` 是带符号 Ic 回落平台。
- 自动 `Ha(Vce)`/`Hb(Ic)` 平台线必须按本次关断局部窗口的稳定带中心取得：`Ha` 取主上升沿前约 `200ns` 基准本地静稳窗口，`Hb` 取主下降沿后本地回落平台；若局部窗口存在单侧毛刺、残余振荡或线宽噪声，应优先复用偏移测量同源的 `Top/Base` 稳定带中心，而不是全波形统计、简单均值/median 或波形带边缘。
- Eoff 自动端点分为两种显式模式：`stable_platforms` 只用于事件包络判为 smooth/无明显振荡、前后稳定带均合格，且候选 A/B 能完整包住本次原始 `Vce*Ic` 主功率峰的关断；其他 smooth 不充分、damped/ringing、稳定带不合格或主峰包含审计失败时，必须回退 `level_crossings`。分型依据是当前关断事件波形，不得按文件名、电流点、温度或桥臂特判。
- `stable_platforms` 模式下，`A` 是 Vce 主抬升前合格 Base 稳定带内的代表时刻；`B` 是 Ic 主下降完成后从左到右的第一个合格 Base 稳定带代表时刻。A/B 在时间上表达真实稳定阶段，不再强制与 Ha/Hb 构成波形交点；`Ha/Hb` 仍保持事件局部平台值，不得用 A/B 单点采样值重算。
- `level_crossings` 模式下保持既有专业口径：`A` 是 Vce 持续主上升沿与 `Ha` 的原始插值交点；`B` 是 Ic 主下降后，按本次事件包络/低幅稳定审计选定的原始 `Ic∩Hb` 交点。平台噪声、第一次轻微触线、后续低能 LC 长尾和段边界都不得抢占 A/B。
- 无论自动端点模式为何，发布的 A/B 就是原始 `Vce * Ic` 的真实积分窗，同时是 GUI 光标、参数表/顶部摘要、报告快照和 Excel 写入的唯一窗口；禁止一套 A/B 用于展示、另一套窗口用于积分或报告。
- 稳定带宽度、代表点和局部取景必须随当前采样率与实际波形自适应；不得把某张图中的 `0.4us`、固定 A/B 间隔或固定局部显示窗写成计算条件。
- 积分用原始 `Vce * Ic`。

## Eon 口径

- `Ha` 是带符号 Ic 抬升前平台。
- `A` 是 Ic 主上升沿穿 `Ha` 的真实交点；必须先确认进入持续主上升沿，再取原始波形与 `Ha` 的第一个插值交点，不能让主沿前平台噪声或短暂毛刺抢占。
- 低电流开通时，可以用相对本地 Ha→Top 跨度的轻量脚点（当前 3%）确认本次 Ic 主上升沿，但脚点只允许作为事件门控，不能直接作为最终 A。最终 A 必须回插到该脚点之前最近的原始 `Ic=Ha` 上升交点，并确认脚点之后继续进入同一次主沿；不得用主沿前噪声、毛刺、极短暂触线或不在 Ha 横线上的百分比脚点作为默认 A。
- `Hb` 是 Vce 回落后导通平台。
- 自动 `Ha(Ic)`/`Hb(Vce)` 平台线必须按本次开通局部窗口的稳定中心线取得：`Ha` 取主上升沿前本地静稳窗口，`Hb` 取开通后局部事件窗口内的静稳平台；窗口以约 `200ns` 为基准，不得缩成极短片段，也不得用全波形统计。
- 稳定中心线必须在原始带符号坐标中计算：先识别局部最安静的稳定波形带，再取该带稳健上下边界的中点，例如 `0.5 * (p05 + p95)`；不得对电压/电流先取绝对值后再求中心。
- `Hb(Vce)` 不得直接使用开通后全段 `20%` 分位、全局 `min/max` 中点或被主沿/振荡污染的粗略 base；平滑或静稳搜索只用于找平台中心，最终 `B` 仍必须落在原始 Vce 与 `Hb` 横线的真实交点。
- `B` 是本次开通过程中 Vce 经过主下降后、局部可见阻尼振荡首次达到低幅稳定标准时与 `Hb` 的真实交点。强振荡 Eon 不能因旧交点保护而回落到主低压振荡中途的早交点；只有候选点后约 `200ns` 窗口的峰峰值、p85/p95 偏离和后续反弹都满足低幅稳定审计时，才允许选择比旧稳定点稍晚的第一个合格交点。
- 积分用原始 `Vce * Ic`。
- `Hb(Vce)` 不得因为手动拖动竖向光标后的联动显示值而重标定，平台线仍按自动平台算法取值。
- 若开通段检测窗口在 Vce 真实回落到导通低平台之前结束，`Hb(Vce)` 允许只为 Eon 后平台取值向第二脉冲右侧扩展短尾窗口；该扩展必须以“原短窗误取高压平台、扩展尾窗明显回到低压平台”为触发条件，不能无条件拉低已经与人工基准一致的样例。
- 不得使用主沿前噪声穿越、第一次刚碰平台就截断、稳定后的长尾小噪声/后续 LC 尾巴、最后显著拖尾或段界点作为 A/B。
- Eon 右侧 B 只能看开通过程 `Vce` 主下降沿与开通本地 `Hb(Vce)` 的回落交点。

## Err 口径

- `Ha` 必须取 `_err_recovery_settled_base` 选出的本次恢复过程中第一个合格无明显振铃稳定带：在该带的原始带符号 `Irr` 样本上取 `0.5 * (max + min)`。它不是 `I_RM` 主峰、全波形 `Top`，也不是由整个可见屏幕的 histogram 模态决定；孤立单点毛刺由稳定带的共享毛刺保护排除。
- 首个合格稳定带还必须通过后续平台稳定性门禁：其后至少 `180ns` 可用观察窗内若存在显著不同且更稳定的后续平台，则该带视为缓降过渡台阶，不能提前作为 `Ha`；检查窗最多向后扩展至 `420ns`，短记录不足时不强行判定。
- Err 的局部放大窗口以约 `200ns/div` 的参数观察窗口为显示软基准，必须覆盖本次反向恢复事件、`B(Vd-Hb)` 和主要恢复尾段；显示取景与 `parameter_local` 稳定带搜索分离，不得把内部搜索范围直接当作屏幕范围，也不得写死左侧 `0.4us` 或固定 `2us` 统计窗。
- IRM 主峰和恢复振荡收敛只用于确定稳定带、A 搜索锚点和必要的显示内容；不得把主峰 `peak` 或显示窗口内的后态极值直接当成 `Ha`。
- `A` 是这条稳定带中点 `Ha` 横线与 Irr 曲线在恢复区入口附近的真实交点；低电流强振铃样例不得使用早期振铃里第一次碰到 `Ha` 的交点，必须等主要恢复振铃结束后的稳定门再找原始交点。
- 中等和高电流 Err 的 A 也不得被“后面更安静”的 legacy 尾窗抢走：若 envelope gate 后已经出现本次事件内第一个合格低幅入口，应使用该入口附近的原始交点；正向软恢复的低幅早入口和高电流负向尾平台的稳定窗结束后交点都必须作为保护分型处理。
- v11 的正向软恢复低幅早入口只允许用于带符号 `Ha` 可分辨、且 `abs(Ha) >= 1% * abs(IRM peak)` 的样例；若 `Ha` 低于该下限，早入口容易被近零平台伪 Top 和尚未结束的大振荡抢占，必须先等待 `_err_recovery_settled_base` 给出的第一个稳定入口，再从该入口之后选择原始带符号 `Irr` 与带符号 `Ha` 的真实交点。
- 低电流 Err 也必须遵守同一稳定带原始中点规则；若默认稳定带样本不足，只能在同一事件内回退到明确的合格稳定带，不能因局部屏幕较宽而重新用 `scope_top_base()` 统计整窗或 `abs(Irr)` 包络边缘。
- 积分也必须使用同一个 A，不得用拟合点或旧首个下降点代替。
- `Hb` 是第二脉冲开通过程/反向恢复段内、Vd 主上升沿前的本地 Base，不是全局 Base，也不是第一脉冲关断 Base。实现以 B 交点前的事件局部安静带（当前为 B 前约 `35~155ns`）为取样范围，在原始带符号 Vd 上取 `0.5 * (max + min)`；不得把 B 后的阻断 Top、整屏 histogram 或主上升沿尾巴混入 Hb。
- `B` 唯一口径是同一段 Vd 曲线与 `Hb` 横线在主上升沿上的真实插值交点。
- `Hb` / `B` 的 offset 精修也必须通过同一 Vd 主上升验收；只有原候选不满足主上升验收时，才启用 `pulse2_on` 下界重算。`pulse2_on` 不是无条件硬下界，避免误伤真实 Vd 上升略早于该事件点的历史样本。
- GUI 中 Err 的物理左侧光标通常是这个 `B(Vd-Hb)`，物理右侧光标通常是 `A(Irr-Ha)`；不得因为左右位置习惯把 Err 的 `A/B` 字母语义与 Eoff/Eon 混用。
- 积分窗口取 A/B 之间，积分用 `abs(Vd) * abs(Irr)`。
- 不得再使用主沿前 0V 附近噪声上穿点、主峰前最后一次上穿点、固定 `400~800ns` 尾窗、拟合点、段界点、最后更小尾窗或旧兼容分支作为 A/B。
- Err 的“从 IRM 尖峰往后第一个达到低幅稳定标准”用于选择 `Ha` 稳定带和 A 搜索起点；`Ha` 数值与该带绑定，始终按原始 `Irr` 的 max/min 中点取得。
- Err 右侧 `Irr-A/Ha` 的稳定锚点必须取“主要反向恢复振荡结束后，第一个同时满足低峰峰值、中心接近本地平台、后续无明显反弹的位置”；若找不到合格入口，不得改取更靠后的最安静尾巴或最后一个尾窗，只能回退到本次恢复事件内的较早有效锚点并等待人工验证。
- 这里的“第一个”必须以合格为前提：若更早入口只是宽松稳定、局部峰峰值明显高于后续候选，则不能抢占后续更低峰峰值且仍在本次事件内的入口。
- Err 的 Vd-B 仍必须是第二脉冲开通过程/反向恢复段内 Vd 曲线与本地 `Hb(Vd)` 横线的真实交点。

## 损耗卡尺统一专业口径

- Eoff/Eon/Err 损耗卡尺左侧起点按对应主沿进入有效重叠区确定。
- Eon 的左侧 A 以及 Eoff `level_crossings` 回退路径的左侧 A，必须是对应本地平台横线与持续主上升沿的第一个有效原始插值交点。平台噪声短暂穿越不得抢占 A。Eoff `stable_platforms` 路径的 A 改为 Vce 主抬升前合格 Base 稳定带代表点，不适用交点强制约束。
- Eon/Err 以及 Eoff `level_crossings` 回退路径的右侧终点必须考虑本次开关过程右侧的有效阻尼振荡，落到“本地平台横线与对应波形曲线”的真实插值交点。Eoff `stable_platforms` 路径的 B 改为 Ic 主下降后首个合格 Base 稳定带代表点。
- 三类损耗的右侧判定不能混用。
- 右侧震荡是否结束必须看本过程对应波形在本地窗口内的最大值、最小值及峰峰值。
- Eon 以及 Eoff `level_crossings` 回退路径的右侧 B 本地判断窗口采用“约 200ns 基准窗口 + 事件完整包络 + 上限保护”：窗口不得因为追求灵敏而缩成很短片段；若事件包络超过 200ns，应扩展到覆盖主沿、候选交点和主要可见振荡，但不得为后续低能长尾无限右扩。
- 严重振荡工况下，平缓区的 `max-min` 必须明显缩小后才能落右侧竖向光标。
- 必要时可对判定用波形做短窗平滑以排除采样毛刺。最终 Eon/Err 和 Eoff `level_crossings` 的 A/B 必须回到原始波形交点；Eoff `stable_platforms` 的 A/B 必须回到原始时间轴上的合格稳定带代表点。
- 右侧 B 的稳定判定应先收集主沿后的平台穿越候选，再用本过程波形的包络、峰峰值、中心漂移、斜率/变化率和后续反弹判断是否进入低幅稳定区；满足收敛条件后，才取稳定区入口附近的真实交点。
- 平滑 Eoff 只在局部低峰峰值、低 p95/median 偏离、未来无明显反弹、前后稳定带均合格且 A/B 包住主功率峰时，才允许发布 `stable_platforms`；后续仍有可见尾振或任一审计失败时回退 `level_crossings`。
- Err 的 `Irr-A/Ha` 可以基于主 IRM 后的包络收敛后移，正向和负向尾段都适用；包络收敛只负责选择稳定带与搜索区，最终 `Ha` 必须来自首个合格无振荡带的原始带符号 `0.5*(max+min)` 中点，不得被局部屏幕的偏移测量 Top 或单点 peak 接管。
- Err 的包络收敛不得退化成“取最后尾巴”：主恢复振荡结束后应从左到右寻找第一个合格低幅入口；后续更安静但明显更晚的尾段只能作为反弹审计依据，不能作为默认 A。
- 对 `WH_600V_285A_000.tss`、`VL_600V_285A_000.tss`、`WL_750V_1050A_000.tss` 这类人工标定样例，默认 Err A 必须分别保护正向软恢复早段低幅入口、早于 legacy 的 envelope 候选入口、以及高电流负向尾平台稳定窗结束后的真实交点；不得用单一“最后安静尾巴”规则覆盖三类分型。
- Err 的 `Vd-B/Hb` 不随 `Irr-A/Ha` 合并或后移，仍必须是同一段 Vd 曲线与本地 `Hb(Vd)` 横线在主上升沿上的真实交点。
- 自动 Eon/Err 和 Eoff `level_crossings` 光标按对应横向平台线与波形的真实插值交点落点；Eoff `stable_platforms` 光标按前后合格稳定带代表点落点。用户进入手动自定义后，`A/B/Ha/Hb` 四根光标必须解耦，拖动 A/B 只改变积分时间窗，拖动 Ha/Hb 只改变显示/记录的手动参考电平。
- Eoff `level_crossings` 路径的主沿拟合或平滑判断只能用于排除前沿噪声并定位真实主上升沿；最终 A 必须重新落到原始 `Vce∩Ha` 的线性插值交点。Eoff `stable_platforms` 路径必须使用主沿前合格 Base 稳定带代表点，不得回退成段首或任意固定偏移点。
- 除 `di/dt`、`dv/dt` 斜率测量外，其他参数进入交互后同样默认使用独立光标；横向光标用于显示或人工记录当前值，纵向光标用于定义时间窗，二者不得在拖动时互相带动。
- 手动自定义损耗重算时，积分窗口必须使用用户当前 A/B 时间点排序后的窗口；重新点击同一参数时，必须恢复用户手动保存的 A/B/Ha/Hb，而不是重新套用默认光标。
- 默认新口径可通过环境变量 `DPT_LOSS_CURSOR_MODE=legacy` 回退到旧损耗光标行为；legacy Err 会回到旧稳定 base 近似，用于发布后对照验证。
- Eon 平台线局部稳定中心可通过环境变量 `DPT_LOSS_PLATFORM_MODE=legacy` 单独回退到旧平台选择；`DPT_LOSS_CURSOR_MODE=legacy` 也会同时触发旧平台选择，便于整套旧光标行为对照验证。
- 损耗 MATH 曲线或 B 之后剩余能量只能作为辅助校验，不能作为右侧 B 的主定义；Eoff B 仍只由 `Ic` 的主下降后 Base 稳定带或 `Ic∩Hb` 回退交点确定，Eon 仍看 `Vce`，Err 仍按 `Irr/Vd` 各自口径确定。
- 不要保留“第一次刚碰平台就截断”“贴近旧交点则沿用”“固定尾窗”“最后显著拖尾”“hold 均值防抖后返回原始小穿越”“B 太近就跳到固定时间点”等旧分支。
- 不要为了追求更晚光标把稳定平台之后的长尾无限纳入积分。
- 当前实现按损耗类型分别锚定对应主沿，并对 Eoff 输出明确端点模式。任何模式下，光标落点、原始 V×I 积分、Pmax 取值、表格、快照和报告都必须复用同一个 A/B 时间窗。Eon/Err 的现行交点口径不受 Eoff 分型影响。

## Trr 口径

- Trr 自动结果、默认光标落点、参数表和报告必须直接复用 `metrics/irr_measure.py::default_irr_trr_measure()` 返回的同一个 `IrrTrrMeasure`，不得由 GUI、pipeline 或导出层各自重建参考线和交点。
- 默认测量源固定为当前通道映射、源/显示反相已经各按声明作用一次后的原始带符号逻辑 `Irr`；不得改用当前高亮通道、可见 Math、`abs(Irr)` 或屏幕抽稀曲线。
- `Hb` 是 `irr_parameter_peak_index()` 锁定的有符号反向恢复主峰 `I_RM`。高负载下桥/negative-first 记录可能先出现绝对值更大的负向前向换流平台，再出现幅值较小的正向恢复主瓣；该负平台只表示恢复前态，不能仅因绝对值更大就被选成 `I_RM`。只有同时证实事件头部为持续负平台、正向候选位于负向谷值之后且明显越过本地噪声下限时，才把后续正向恢复主瓣选作有符号 `I_RM`；证据不足的近零或普通双极波形继续沿用既有有符号主瓣规则，不得按桥臂名硬翻极性。
- `stable_level` 是该峰后本次恢复事件的稳定平台中心：优先沿用峰后 `300ns~600ns` 的本地恢复平台窗，短记录才使用峰后现有短尾；最终取孤立毛刺保护后稳定波形最大值与最小值的平均中线。
- 默认 `Ha = stable_level`。Ha 必须直接卡在峰后恢复稳定平台本身的 `0.5*(max+min)` 中线上，不是恢复平台与 `I_RM` 峰值之间的 50% 半幅线，也不是反向恢复 `di/dt` 的 `50%IF→50%IRM`。
- `A` 从本次反向恢复事件窗起点开始搜索，是同一条带符号逻辑 `Irr` 主瓣向 `I_RM` 峰值变化时与 `Ha` 的第一个原始插值交点；不得只回看峰前固定 300 点而漏掉慢沿或高采样率记录的真实首交点。`B` 是峰后主瓣由 `I_RM` 回落到恢复平台时与同一 `Ha` 的第一个原始插值交点。必须满足 `A < peak < B`，后续振铃再次穿越 `Ha` 不能替代第一个 B。
- 默认 `Trr = B - A`，单位 ns；默认圆点必须真实落在 `LOGIC_IRR∩Ha`。不得把峰/平台半高、`A=0A`、`Hb=25%I_RM` 或尾段拟合外推零点混入该定义。
- 若分段器初始 RR/开通段尾点早于权威 `I_RM` 主峰或其后的回落交点，Trr 权威窗口必须至少覆盖 `irr_parameter_peak_index()` 返回的峰点和本次主瓣回落尾点，再搜索 B；但 `pulse2_off` 是不可越过的硬事件上界，其指向第二脉冲关断事件的第一个采样点，峰搜索、峰后恢复稳定平台取样、A/B 交点和任何扩展尾窗都只能使用 `pulse2_off` 之前的原始有限样本。该扩展只用于 `Trr` 的 Ha/A/B 主恢复瓣交点，不得顺手扩展 Err 积分搜索尾窗或改变 Err A 口径。
- 若第二脉冲关断发生在有效 `I_RM` 峰完成之前，或峰后到 `pulse2_off` 之间不足 3 个有限原始样本，Trr 必须 fail-closed 为不可用；不得跨过关断去找更大峰、稳定平台或 B，也不得拿关断后的平台/尖峰作兼容回退。
- Trr 只统计主恢复时间，不能因为 Err 能量窗口需要有效尾段就把 Trr 的 B 拖到后续衰减振荡结束。
- Trr 是非斜率卡。进入手动状态后 A、B、Ha、Hb 四根光标保持独立可移动并保存，任一根都不得吸附或联动覆盖其他光标；手动 Trr 只按当前 A/B 的时间差更新，手动 Ha/Hb 作为用户参考线，不再冒充默认恢复平台上下文。重新加载或清除手动状态后才恢复上述自动平台线定义。
- 不得恢复 `reverse_recovery_trr()` 的固定 `5A` 近零阈值、GUI 默认区间的前窗 `mid` 口径、峰/平台半高、`0A→25%I_RM` 尾段外推，或任何自动表格/默认卡尺/报告各算一套的分支。

## dv/dt 与 di/dt 横向光标

- `dv/dt`/`di/dt` 的 `Top/Base` 或 `Ha/Hb` 必须来自同一个参数本地测量上下文，并与 10/90、90/10 参考线、A/B 交点、表格值和报告值使用同一套口径。稳定平台取样窗可以位于真实交点搜索子窗之前或之后，但必须是该参数上下文明确声明的邻接本地窗，不得偷用全波形、旧缓存或另一参数的范围。
- 关断、开通、反向恢复共六个 `dv/dt`/`di/dt` 参数均提供可选的“自动最大斜率”范围；它只替代当前参数的百分比 A/B 范围，不改变该参数既有事件、本地窗口、Top/Base、Ha/Hb、波形源或极性。原有预设、自定义范围和默认选择必须保持不变，不能因新增自动模式而迁移用户默认值。
- 自动模式必须先在当前参数既有主沿内取得宽锚点，依次尝试 `2%→98%`、`5%→95%`、`10%→90%`、`20%→80%`（下降沿按时间顺序反向显示）；没有完整、有序的宽锚点时直接不可用，不得跳到另一脉冲、后续振铃包或全波形导数峰值。
- 宽锚点内固定滑动 `20` 个百分比点的幅值窗口；窗口起点按 `0.5` 个百分比点步进，并补入锚点两端边界。候选必须同时满足：线性拟合 `R² >= 0.80`、沿主方向单调样本占比 `>= 70%`、候选实际幅值覆盖不低于固定窗口的 `70%`，且 `20% >= max(1.5%, 4×本地噪声)`；在合格候选中选择 `20% / Δt` 最大者。轻量中值/三角平滑只用于定位，不得用平滑波形生成最终数值。
- 最终 A/B、`ΔV/ΔI`、`Δt` 和斜率必须用选中的固定 `20%` 电平重新调用本参数既有原始波形交点函数。最终区间不能取得两个真实交点时必须 fail-closed 为不可用，严禁用单点梯度、拟合端点、采样边界或伪造 A/B 回退。
- 自动模式内部结果、状态栏和报告范围文本保留实际结果，例如 `自动 46%→66%（14.2 ns）`；其中百分比差固定为 `20%`，`z ns=|B-A|` 随波形变化。参数表“范围取值”列只显示与普通预设同长度的 `46%→66%`，不显示自动前缀或时间；百分比必须与普通预设一样按完整单元格垂直居中。自动身份由单元格左下红色“自”和右下红色“动”表达，角标不得参与列宽计算或遮挡主体百分比；角标实际包围框接近正文保护区时从 8px 缩到 7px，并以正文排除裁剪兜底。百分比正文必须只有一个绘制入口，不得由默认委托和自定义委托重复绘制造成重影。Ha/Hb 手调后必须在同一参数上下文内重新滑动选择并同步更新实际百分比、时间跨度、A/B、表格和参数范围浮窗。
- 六个斜率参数的“取值范围”分别记忆用户最后选择，并跨 TSS 文件、跨软件重启恢复。普通预设和自定义范围必须持久化完整百分比、参考类型与沿方向；自动最大斜率只持久化“自动”模式，不得保存上一波形求得的实际 `x%→y%`，新波形必须重新滑动固定 20% 幅值窗求解。设置缺失或单项损坏时只把该项恢复为代码默认值，不得连带覆盖其余有效项。
- 反向恢复自动 `di/dt` 固定沿既有带符号 `IDM→Base` 换流主沿选择，保留极性归一化和时间有序 A/B；`50%IF→50%IRM` 仍只属于原有固定/自定义算法选择，不能在自动模式中混入或按绝对值改写。
- 默认开通 `dv/dt` 源为原始逻辑本管 `Vce`：`Ha/Top` 取本次开通主下降沿之前的事件本地稳定高电压平台中心，`Hb/Base` 取主下降沿之后、下一关断事件之前的稳定低电压平台中心；不能取全段最大/最小值、孤立过冲或稳定带边缘分位数。A/B 为原始 `Vce` 按 `Base + pct*(Top-Base)` 得到的 `90%→10%` 真实插值交点。
- 开通 `dv/dt` 先保持历史开通段搜索；只有该段缺少完整、有序的 `90%→10%` 原始交点时，才允许把同一电平和同一波形的搜索末端延长到 `pulse2_off`。延长后仍缺任一交点时不得用导数峰值伪造 A/B；普通样例在原段内已完整时数值不得漂移。
- 默认反向恢复 `dv/dt` 源为原始逻辑对管 `Vd` 的 `abs(Vd)`：`Ha/Top` 统一取本次恢复过冲后的稳定阻断电压平台，`Hb/Base` 取主上升沿前约 `0.4~0.1us` 的事件本地稳定低电压平台；不得再把 `rr_slope_window` 内的 `max(abs(Vd))`、`Vrr`、振铃过冲峰值或硬编码 0V 当成 Top/Base。高平台搜索从过冲后约 `100ns` 开始，在不越过 `pulse2_off` 的有界本地窗内选择约 `200ns` 的低峰峰值、低漂移稳定带；高低平台最终均取孤立毛刺保护后的原始 `(max+min)/2`。A/B 始终为 `Base + pct*(Top-Base)` 与原始 `abs(Vd)` 主上升沿的真实插值交点。
- 开通与反向恢复 `dv/dt` 的 Ha/Hb 都必须套用各自事件本地稳定高/低电压平台居中规则，并各自由一个纯 `DvdtMeasurementContext` 一次性给出 Top/Base、阈值、原始 A/B、斜率与 fallback 状态。pipeline 参数表、GUI 默认卡尺/读数和报告复用同一对象；默认卡点击属于显示，不得改写既有 pipeline 数值。
- 极慢栅极关断先使用既有 pulse-local Vge 下降窗；仅当紧凑窗内 `98%/95%/90%` 三个真实下降交点均缺失时，才向同一第一脉冲内更早位置扩展搜索。该兜底用于恢复 Vge 下降起点及关断 `Td_off/Tf/Toff`、`dv/dt/di/dt` 的同源窗口，不得跨入其他脉冲或改变已在主窗完整的样例。
- 真人目视复核稳定平台线时，以稳定段可见最大值与最小值的平均值作为是否居中的首要判据；孤立毛刺/过冲不属于稳定段边界。所有命名为 `Top/Base` 的电压或电流参考均表示参数本地稳定高/低平台；`Ic_off_max`、`Vrr`、`Vce_on_max` 等显式 `max/peak` 参数保持独立，禁止反向冒充 Top/Base。
- 关断 `di/dt` 的原始 A/B 首先在 Vge 关断主沿窗口内查找；若任一百分比交点缺失，才允许把搜索终点有限延伸到已经声明的参数本地窗口末端，并且只有同时得到有序的真实 A/B 才采用扩窗结果。不得用无真实双交点的数值梯度结果冒充 GUI 卡尺。
- 参数表和报告的“范围取值”只显示当前百分比标签，例如 `90%→10%`；本次 Top/Base/Ha/Hb/H0 数值只用于状态栏诊断，不得混入范围列。
- 反向恢复 `di/dt` 必须由一个纯 `RrDidtMeasurementContext` 同时给出带符号前向平台、恢复尾基准、反向峰、极性、原始 A/B、百分比阈值、斜率及 fallback 状态；pipeline 参数表、GUI 默认卡尺/读数和报告必须直接复用这一个上下文，不得分别重新推断平台、极性或交点。
- `measure=idm` 的原始带符号显示语义固定为：`Ha` 是主要恢复结束后的本地稳定尾基准（物理零附近的 `Top`），`Hb` 是换流前带符号 `IDM` 稳定平台（negative-first 原始显示中的 `Base`）。先取得同一事件邻接的换流前宽候选区：若其稳健跨度和原始中点都证明整区稳定，保留整区孤立毛刺保护后的原始 `0.5*(max+min)`；只有当宽候选区的稳健跨度显著大于其约 `200ns` 低峰峰值、低漂移子带，且整区中点也被显著拉偏时，才判定边缘已混入换流沿并改用该安静子带的原始 `0.5*(max+min)`。不能无条件缩窗，也不能用 P5/P95、mean、median、全波形统计、尾段单点或波形带边缘替代最终平台值。稳定平台候选区允许位于 A/B 搜索子窗之前，但不得包含主换流沿或把后续相反符号恢复峰误当成 `IDM`。
- `measure=idm` 先用 `p = sign(IDM - Base)` 归一化逻辑电流 `q(t) = p * (Irr(t) - Base)`，使前向平台恒为正、恢复到 Base 恒为下降；再按 `q` 的 `90%→10%` 依时间从左到右查找持续有效的原始插值交点，必须满足 `tA < tB`。当原始前向平台为负时，物理 `Irr` 主沿看起来是上升，但 A/B 不得因此交换，斜率仍报告为正的幅值。
- `measure=if_irm` 的原始带符号显示语义固定为：`H0` 是本地零基准，`Ha` 是带符号前向 `IF`，`Hb` 是带符号反向 `IRM`；先在同一极性归一化坐标中按时间顺序查找 `50%IF→50%IRM`，不得用绝对值搜索制造伪交点。
- 通道设置中的人工反相必须先作用到当前逻辑 `Irr`，随后只执行一次上述自动极性归一化；不得再依据文件夹名或桥臂猜测二次反相。正负平台必须使用同一个、相对于恢复峰声明的邻接稳定平台窗和带符号中心规则；若该窗的幅值偏离事件极值平台超过保护比例，则拒绝该窗并保留极值局部平台。不得让探头方向改变同一物理事件的 A/B 或斜率。
- `dv/dt`/`di/dt` 必须同时保留两种不可混用的读数：参数范围浮窗取原始波形在实际 A/B 百分比交点处的绝对差值及其 `Δ/Δt`，与参数表、状态栏和报告中的斜率数值一致；原位置的横向光标浮窗则始终显示完整 `|Ha-Hb|` 以及 `|Ha-Hb|/|B-A|`，用于人工观察两条横向光标的实际间距，不得再强制与百分比参数值相等。参数范围浮窗放在顶部 `Δt / 1/Δt` 浮窗旁，横向光标浮窗继续留在 Ha/Hb 单点读数下方；本条仅区分显示职责，不改变 Top/Base、百分比阈值、A/B、参数计算或报告值。
- 横向光标显示应落在稳定波形带的视觉中心线上；反向恢复 `di/dt` 的稳定带明确使用孤立毛刺保护后的原始 `0.5*(max+min)`，其余参数继续按各自已声明的本地稳定带/Top/Base 口径。任何参数都不得先取绝对值再求中心，也不得让另一参数或当前高亮通道的波形抢占 Ha/Hb。
- 斜率卡的 A/B 必须保持为 Ha/Hb 百分比参考线与本参数原始波形的自动交点，不能提供独立手动拖动；真人调整只移动 Ha/Hb，并由同一测量上下文立即重求 A/B 和斜率。交互命中范围可以在显示层扩大，但不得改变平台、百分比、交点或数值公式。

## 双脉冲原则

- 双脉冲文件必须识别为双脉冲时，关断取第 1 脉冲，开通/反向恢复取第 2 脉冲。
- 不能退化成单脉冲，也不能把开通窗落到错误平台。

## 单脉冲原则

- 单脉冲 TSS 数据只有关断过程，不包含有效的第二脉冲开通、反向恢复、Eon、Err 或开通 di/dt。
- 遇到单脉冲样例时，算法和验证脚本必须进入单脉冲/仅关断口径。
- 只提取并验证 Vdc、Idc、关断 `Delta Vce`、关断 `dv/dt`、关断 `di/dt`、`Ls_off`、`td_off/tf/toff`、Eoff、关断串扰等关断参数。
- 不要把缺失的第二脉冲当成算法失败。
- 不要为了凑 Eon/Err 人为构造开通窗。

## 关断 Delta Vce 光标语义

- 关断 `Delta Vce` 的数值口径保持 `Vce_off_max - vce_off_top`：横向 `Ha` 卡关断尖峰最大值，横向 `Hb` 卡尖峰后的稳定 Top 平台值。
- 竖向 A/B 表达该参数的物理取值范围，而不是横向电平的两个交点：A 卡在 Vce 抬升前最后一段安静 Base 稳定带，B 卡在尖峰后第一段安静 Top 稳定带，必须满足 `A < 尖峰 < B`。不得把 A 放到尖峰，也不得把 B 放到上升沿或振铃首次碰到 Top 的位置。
- A/B 与 Ha/Hb 四根光标保持独立；默认竖向范围变化不改变自动数值，人工 Ha/Hb 变化继续按既有手动 `Delta Vce` 规则更新数值和 `Ls_off` 幅值校准。拖动过程中只做轻量读数，释放后才提交计算和持久化。

## 开通电流、开通 di/dt 与 Ls_on

- 开通电流/开通 di/dt 的 `Ha` 必须共用同一套 Ic 抬升后平台逻辑并保持一致。
- 默认开通电流光标的 `Hb` 使用带符号逻辑 Ic 抬升点前 `250ns~50ns` 的完整原始稳定带；只对孤立单采样毛刺做保护，再按该带原始 `max/min` 的中点 `(max+min)/2` 取值，不得改取安静子窗、分位数、均值或中位数。毛刺保护必须覆盖稳定带内部以及首点/末点；边界点先用同一稳定带内紧邻的两个采样判断，短窗内多个稀疏毛刺互相污染全带阈值时，只允许迭代排除“当前仍决定剩余带 `min/max`、立即邻点一致且两侧可用外延均保持平台”的可证单点；端点还必须有连续第三个带内邻点证明平台延续。真实斜坡、连续/阻尼振铃、多采样异常或证据不足的四点双端形态一律保留原始 `max/min`，不得为了清理合成毛刺误删连续波形。
- 默认开通电流光标的 A 在 `Hb` 稳定带起点到抬升点后 `30ns` 的范围内，取原始带符号逻辑 Ic 与 `Hb` 的最后一个上升插值交点。
- 若 A 早于 `Vge10-detect_window`，必须把 `Hb` 稳定带左边界裁到 `turn_on[0]` 后重新计算 `Hb/A` 并再次校验；裁剪后的 A 仍过早或范围内没有原始上升交点时，A 必须为不可用（`NaN`），不得回退到最近采样点或线段端点。
- 上述规则只约束默认开通电流的 `Hb/A` 光标；`Ha`、B、pipeline 数值结果、开通 `di/dt` 和 `Eon` 均不变。
- 开通 `Delta Vce` 的下点是 Vce 主下降过程中的拐点/平台点。若 Vce 在主下降前先跌落到一个可见且持续的短稳定平台，下点优先取该平台内最平稳小窗的 `(max+min)/2`，而不是继续落到后续主下降段；两斜率边沿的固定导数门槛落入主下降深处时，允许用平缓预降段与主下降段的局部趋势线交点恢复真实拐点，但必须校验斜率差、压降范围及交点与实际平滑边沿的距离。该回退不得改变开通 `dv/dt` 的稳定 Top/Base、百分比交点或任一其他参数口径，也不允许改成全段最小值或损耗窗口点。
- 换流回路杂散电感统一使用 `L = integral(uL dt) / abs(Delta I)`。`Ls_on` 的 `uL=max(Vce Top-Vce,0)`，A/B 默认与开通 `di/dt` 的真实 Ic 百分比交点共用；`Ls_off` 的 `uL=max(Vce-Vce blocking Top,0)`，在关断 `di/dt` A/B 搜索边界内只取包含主尖峰、超过 `max(0.5V, 5%峰值)` 的连续正过冲瓣。分子电压面积和分母电流变化必须严格同窗。
- `Delta Vce` 仍是 Ls 的电压幅值校准变量，不得解耦：手动 `Delta Vce` 变化后，当前 Ls 电压面积按 `Delta Vce manual / Delta Vce automatic` 线性缩放并实时更新。不得把“同窗积分”误解为取消该联动。
- `Ls_on/Ls_off` 使用独立 A/B 积分窗且绑定逻辑 Ic，Ha/Hb 不适用；手动调整 Ls A/B 不能改写 `Delta Vce` 或 `di/dt`。自动结果不得按样本组做归一化，也不得使用固定经验修正系数。

## 短路 Tsc 口径

- 短路时间 `Tsc` 默认取值范围命名为 `0%-0%`，对应短路电流相对基线 `Hb` 的上升沿/下降沿交点。
- `10%-10%` 取值范围以短路电流最大幅值为 100%，用上升沿 10% 与下降沿 10% 作为计算阈值，A/B 纵向光标卡在对应电流曲线与阈值的真实交点。
- 修改 `Tsc` 取值范围只改变短路时间的 A/B 光标和 `Tsc` 数值；短路能量窗口不得因此被联动缩窄，也不得新增额外虚线辅助标记。
- 短路电流和 Vge 的平滑结果只允许用于事件检测与搜索限界；`Imax/Esc/Tsc/Vpeak` 的最终 A/B 必须回插到原始波形与声明横向电平的真实插值交点。原始本管 Vge 没有一对合法 Base 交点时，本管/对管 Vpeak 均不可用，不得用全记录窗口或占位时间计算。
