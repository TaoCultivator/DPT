# TSS 回归样例、数值快照与全量验证

本文记录 DPT 项目的重点 TSS 样例、数值快照和验证要求。凡是修改 TSS 提取、脉冲分段、平台线、损耗窗口、光标落点、积分、斜率、Trr/Err 或任意会影响参数数值的逻辑，必须阅读并执行本文。

## 全量验证红线

- 凡是修改 TSS 提取、脉冲分段、平台线、损耗窗口、光标落点、积分、斜率、Trr/Err 或任意会影响参数数值的逻辑，完成后必须清理/绕开旧验证缓存。
- 必须使用 `示例文件` 下全部原始 `.tss` 文件重新跑全量验证训练。
- 必须同时覆盖双脉冲与单脉冲样例。
- 不得只跑两个黄金样例。
- 不得只看单个截图。
- 不得拿缓存结果冒充重新验证。
- 全量验证失败、异常数增加、单脉冲被误判为双脉冲、或任一重点样例数值无依据漂移时，不能交付。
- 跑 pytest（全量或定向）必须显式指定 `--basetemp` 指向**工作区内**目录，例如：

  ```powershell
  .\.venv\Scripts\python.exe -B -m pytest -q -p no:cacheprovider --basetemp=.tmp\pytest-tmp --junitxml=.tmp\pytest.xml
  ```

  原因（环境问题，与代码无关）：本机 `%TEMP%\pytest-of-songzhenxi` 由其它沙箱账号创建，当前账号连它的 ACL 都读不到；省略 `--basetemp` 时 pytest 会在约 `10.6s` 内以 985 个 `setup error` 全灭（`PermissionError: [WinError 5] ...\AppData\Local\Temp\pytest-of-songzhenxi`）。**不得删除、移动或改动该目录及其 ACL**，只做 `--basetemp` 绕行。
- 任何“某失败是不是本次改动引入”的定性，必须用 HEAD（或对应发布 tag）干净检出做对照实验后才能写结论；未做对照的一律记为「未定性」，不得写成「本就失配」。禁止用“重新标定 golden / 更新期望值”消化失败来掩盖回归。详见文末「2026-10-15 HEAD 对照实验」节。

## Err 兼容性校准样例

全量验证不能只看 Err 数值闭环，还必须检查放大后卡尺是否贴波形。

`Ha` 不再允许使用固定峰后 `400~800ns` 尾窗，也不允许使用全波形 Top/Base。必须先在 IRM 主峰后、本次开通过程结束前，用滚动局部极差和包络收敛找到主要大振荡已经结束的本地锚点；再按 Err 参数局部放大窗口内的偏移测量 Top 口径取得 Irr Top，作为 `Ha`。

若当前 Err 光标使用有符号 `Irr` 曲线，且该局部 Top 为有效负尾段，`Ha` 必须保持带符号负值，不能翻成正的 `abs(Ha)`。低电流样例若完整局部窗口 Top 被早期大振铃污染，必须只在同一个参数局部窗口右半稳定范围内重取 `scope_top_base()` Top，不得改用 `abs(Irr)` 局部包络边缘或旧稳定窗中点。
