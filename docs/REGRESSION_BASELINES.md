# TSS 回归样例、数值快照与全量验证

本文记录 DPT 项目的重点 TSS 样例、数值快照和验证要求。凡是修改 TSS 提取、脉冲分段、平台线、损耗窗口、光标落点、积分、斜率、Trr/Err 或任意会影响参数数值的逻辑，必须阅读并执行本文。

## 全量验证红线

- 凡是修改 TSS 提取、脉冲分段、平台线、损耗窗口、光标落点、积分、斜率、Trr/Err 或任意会影响参数数值的逻辑，完成后必须清理/绕开旧验证缓存。
- 必须使用 `示例文件` 下全部原始 `.tss` 文件重新跑全量验证训练。
- 必须同时覆盖双脉冲与单脉冲样例。
- 不得只跑两个黄金样例。
- 不得只看单个截图。
- 不得拿缓存结果冒充重新验证。
- 全量验证失败、异常数增加、单脉冲被误判为双脉冲、或任一重点样例数值无依据漂移时，不能交付。

## Err 兼容性校准样例

全量验证不能只看 Err 数值闭环，还必须检查放大后卡尺是否贴波形。

`Ha` 不再允许使用固定峰后 `400~800ns` 尾窗；必须在 IRM 主峰后、本次开通过程结束前，用滚动局部极差找到主要大振荡已经结束并首次达到低幅稳定标准的稳定窗，并以该窗内 `(max+min)/2` 作为 Irr base 有效值。

若该稳定窗为有效负尾段，`Ha` 必须保持带符号负值，不能翻成正的 `abs(Ha)`；正幅值软恢复才用幅值口径显示/交点。

`A` 必须是这条 `Ha` 横线与 Irr 曲线在稳定区入口附近的真实交点，不得继续用主峰后第一个下降穿越、固定尾窗交点、后续更小尾窗交点、拟合点或段界点。

`Hb` 必须取第二脉冲开通过程/反向恢复段内，对管电压 Vd 主上升沿前的本地 base，`B` 必须卡在 `Hb` 横线与同一段 Vd 主上升沿曲线的真实交点上，这是唯一口径；不能取全局 base、第一脉冲关断过程 base、主沿前基线毛刺、拟合回推点或旧兼容点，也不能保留“主峰前最后一次有效上穿/旧交点贴近则沿用”的兼容分支。
