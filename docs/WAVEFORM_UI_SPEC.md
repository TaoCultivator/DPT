# 波形界面与交互规则

本文记录 DPT 项目中波形显示、通道标识、表格展示和交点示意点的规则。

## 通道标识位置

- 波形通道标识必须贴该通道的 0 刻度位置显示。
- 不要把通道标识锚到波形曲线、损耗窗口曲线或其他非 0 刻度位置。

## 结果表分区名称

- 双脉冲结果表的三个过程分区统一显示为“关断过程”“开通过程”“反向恢复过程”。
- 代码内部仍使用既有 `关断过程`、`开通`、`反向恢复` 键进行参数计算、交互和报告映射；显示名称调整不得改写这些内部键。

## 初始加载位置

遇到波形初始加载位置/通道标识看起来歪、但手动拖动一下标识后恢复正常的问题，优先排查 Qt/PyQtGraph 初始布局时序：

- 在 ViewBox `sigResized` 中强制刷新可见曲线并重新定位 0 刻度通道标识。
- 在窗口 `resizeEvent`/`showEvent` 中强制刷新可见曲线并重新定位 0 刻度通道标识。
- 在波形加载完成后的延迟帧里强制刷新可见曲线并重新定位 0 刻度通道标识。
- 不要用改积分/测量/提取结果来规避。
- 不要把标识锚到损耗曲线窗口来规避。

## USB 示波器波形源与同步

- USB 连接的 Tektronix 示波器是首选实时波形源，TSS 原始文件保留为没有示波器时的备用入口；两种来源进入同一 `WaveformBundle -> 通道映射 -> 项目提取` 链，计算公式与参数口径不得分叉。
- 上位机远程连接示波器后保存的 TSS 若以 `S1_CH1` 等远程源写入 `MAINWINDOW:SOURCEORDER`，这些远程源及其显示标度、位置、反相和标签是当前会话的权威来源；同一设置文件中残留的本机 `CH1~CH8` 标签、Math 和测量项不得污染远程波形。远程通道在项目内继续归一为 `CH1~CH8`，不新增第二套计算链。
- TSS 保存的主时基窗口由 `HORIZONTAL:SCALE/POSITION/DELAY` 恢复，并作为软件“全图预览”的全局时间范围；即使 WFM 内含更长的预取/后取原始记录，也不得把保存主时基误判成局部放大并额外显示一个空旷的长记录概览。用户随后点击参数形成的更窄窗口才属于局部视图。
- Tektronix USB 直读的 VISA 后端按 `TekVISA -> NI-VISA` 选择：仅安装 TekVISA、仅安装 NI-VISA 或两者共存都必须可用，两者共存时必须优先使用 TekVISA。回退只允许发生在后端未安装、无法创建资源管理器或发现/打开身份阶段找不到兼容 Tektronix 资源时；一旦选定后端并开始波形传输或 Zoom/光标同步，超时、二进制块、点数、长度及其他数据完整性错误必须直接失败，不得静默切换后端重试。
- USB 只读取当前记录的时间轴、已开启源通道/Math 波形、单位、标度、位置、标签和必要采集元数据；不得用示波器自动测量结果替换项目计算结果。
- `Normal` 单次触发后即使示波器仍显示等待/采集状态，只要当前记录可查询就必须直接读取，不得强制用户先按 `Stop`。当前记录没有门极跳变时仍要完整显示波形和通道；只允许对应参数计算显示不可用，不能拒绝导入。
- 点击参数默认局部视图时，示波器同步必须使用其缩放/Zoom 窗口，保留全局概览，不得通过直接改主时基破坏原始全局视图。
- 软件局部视图右上角 `X` 和“最近局部放大/全图预览”切换按钮必须同步控制示波器 Zoom：切到全局或点 `X` 时关闭 Zoom，切回局部时恢复对应 Zoom 窗口；没有活动参数光标的纯视图切换不得额外开启示波器光标。
- 软件光标真实手调后，只要用户仍停留在当前局部/手调视图、没有通过 `X` 或全图预览显式退出，再次点击同一参数不得移动软件当前 X 轴窗口；该点击只触发一次同步刷新，把当前软件窗口及 A/B/Ha/Hb 写到示波器 Zoom/光标。拖动过程本身不连续发送 USB 命令。
- 用户通过局部视图 `X` 或全图预览切到全局时，必须保存退出瞬间的精确局部 X 轴窗口且不得清除该参数手调光标；随后再次点击同一参数必须先恢复其刚才的局部窗口和手调光标，再把恢复后的窗口/光标同步到示波器。点击其他参数不得误套用这份待恢复窗口；通过预览按钮直接切回局部时继续恢复同一窗口。
- 顶部相别、上下桥、温区选择、RT/HT/LT 三组实际温度和报告工况必须记忆上次设置。温度与报告工况只分上桥、下桥两套：`UH/VH/WH` 共用上桥一套，`UL/VL/WL` 共用下桥一套；同一桥臂内切换 U/V/W 相不得切换或重置记忆。只有 TSS 明确识别成功的单个字段可以逐项覆盖当前桥臂的对应记忆值，未识别字段一律延用；相别或桥臂未识别时也保持当前选择。示波器读取不得清空或改写顶部设置。

## 拖动性能

遇到拖动通道标识移动波形时卡顿，优先优化鼠标移动热路径：

- 拖动中只刷新当前通道曲线和当前通道 0 标识。
- 鼠标释放后再补 overview、坐标轴、读数、图例等重刷新。
- GPU/OpenGL 只能作为可选绘图后端开关。
- NPU 不适合这种 Qt 波形绘制热路径。

## 偏移测量表

- 偏移测量表的“分区”列只显示短通道名，如 `Ch 1`、`Math 1`。
- 不要带示波器 Label 或逻辑标签。
- 该表正文使用普通字重。
- 文字必须完整显示。
- 保留清晰的行列分割线。

## 交点示意点

波形界面的端点示意点必须服从参数取值规则，并绑定该参数 A/B 声明的语义波形。当端点定义为横向参考线交点时，点必须画在原始波形真实交点；当端点定义为稳定带代表时刻时，点必须采样该 A/B 时刻的语义波形，不得为了贴 Ha/Hb 而移动 A/B。任何模式都不能因竖向光标碰到其他通道曲线就额外打点。

- Eoff `stable_platforms` 模式画 `A=Vce 主抬升前 Base 稳定带代表点`、`B=Ic 主下降后首个合格 Base 稳定带代表点`；两点不强制与 Ha/Hb 横线相交。Eoff `level_crossings` 模式仍只画 `A=Vce∩Ha(Vce)`、`B=Ic∩Hb(Ic)`。
- Eon 只画 `A=Ic∩Ha(Ic)`、`B=Vce∩Hb(Vce)`。
- Err 只画 `A=Irr∩Ha(Irr)`、`B=Vd∩Hb(Vd)`。
- Trr 默认态必须画原始带符号逻辑 `Irr` 主瓣与恢复平台 `Ha` 的 A/B 两个真实交点：`Hb=有符号I_RM峰值`，`Ha=峰后稳定波形max/min平均中线`；A 从 RR 事件窗起点取第一个上升交点，B 从峰值取第一个下降交点。不能用峰前固定点数截短搜索，也不能用峰/平台半高、后续振铃交点、0A 或尾段外推点。
- 当 `Irr=Ic-IL` 或 `Ic=Irr+IL` 只能由内部全分辨率逻辑波形得到、没有同向可见 Math 曲线时，参数光标卡、交点标记、活动纵轴和顶部读数仍必须使用该内部逻辑电流及其真实单位；不得因为逻辑波形没有常驻 `PlotDataItem`、参数进入前已有其他通道高亮，或参数模式中又单击/双击其他通道而回退到 CH1/Vge 或第一个可见通道。其他通道仍可置顶/高亮，但不能夺走无法通过通道栏重新选中的内部测量源。切换到下一个通用区间参数时必须显式绑定该参数的物理通道，不能让旧 `LOGIC_IRR/LOGIC_IC` 跨参数残留；也不得为规避读数问题擅自新增常驻通道栏/报告曲线。
- 所有参数卡都必须显式绑定 A/B 端点和 Ha/Hb 横线的逻辑波形。IEC 跨通道时序保持语义端点，例如 Toff A=Vge、B=Ic；进入参数后单击/双击其他通道只允许置顶/高亮，不能把任一端点改成该通道。离开参数或参数不可用时要清除旧端点、横线、单位、读数和标记，不能串卡。
- 每次点击参数卡必须先清除上一张卡的 `_active_slope_param` 和斜率回调；只有当前可用的 `dv/dt`/`di/dt` 卡建立成功后才能重新激活。非斜率卡、不可用卡或无合法区间卡不能借后续重算、通道高亮或重复点击复活旧斜率卡尺。重新计算会重绘波形，但不能只保留表格选中态：若活动卡仍有效，必须恢复该卡完整的 A/B、Ha/Hb、端点通道和读数上下文；若活动卡仍不可用，必须恢复无 A/B、无横线、无读数的空上下文，禁止回落到带全局 `MATH` 光标的假参数状态。顶部相别或桥臂切换属于测试上下文切换，不属于参数卡重进；其重算完成后必须停留在全局波形视图，不得恢复旧活动卡并触发局部放大。
- 自动 Eon/Err、Eoff `level_crossings` 和自动 Trr 的圆点是相应语义波形与横线的真实交点；自动 Eoff `stable_platforms` 的圆点则采样默认 A/B 时刻的 Vce/Ic。用户手动解耦 A/B 与 Ha/Hb 后，圆点一律采样当前 A/B 时刻的语义端点波形，继续证明端点属于哪条曲线。不得把圆点留在旧横线电平形成悬空点，也不得隐藏内部 `LOGIC_IRR/LOGIC_IC` 的端点标记。
- 功率卡仅在可信 W/kW Math 轨迹与原始 V×I 匹配时让该轨迹同时绑定 A/B/Ha；Math 候选切换、失配或隐藏时，A/B/Ha、有效性、活动轴和辅助点必须一次性整体切换。关断/开通 `Pmax` 无可信 `Vce*Ic` 功率轨迹时，A/B 继续使用损耗定义的原始 V/I 边界，`Ha` 必须通过不进入通道栏、不生成报告曲线的只读 W 坐标显示当前 A/B 窗内原始 `Vce*Ic` 最大值，`Hb` 隐藏；不得把文件中仅适用于反向恢复的其他 Math 冒充 Pmax。反向恢复 `Pdmax` 无可信功率轨迹时继续隐藏 Ha/Hb。首次进入或仅点击功率卡不得改写参数值；用户主动拖动 Ha 并释放则属于明确的人工参数校准，必须把换算后的 kW 值同时保存到当前结果、表格和报告快照，切换参数后恢复同一物理横线。拖动期间仍只更新读数，不能连续重算或写报告状态。
- `Pmax/Eon/反向恢复 Pdmax` 恢复手动区间或重新进入时，可见 Math 仍只能恢复显示卡尺；没有人工 Ha 时，卡值和报告值必须由当前 A/B 窗内的原始 `Vce*Ic` 或 `abs(Vd)*abs(Irr)` 重新确认。已有人工 Ha 时必须以该人工值为准，直到换文件、重新计算或显式清除手调状态；Math 的 V/div、偏移、公式显示单位或缩放峰值不得擅自写回参数结果。
- 通道设置中的显示反相属于波形坐标变换，不是纯视觉高亮。反相状态改变后，重算前必须沿当前通道映射、派生逻辑电流和 Math 公式依赖闭包，清除所有依赖该源的手调 A/B、Ha/Hb/H0、极值、能量与 Trr 状态；未依赖该源的手调状态可以保留。当前参数若自动重进，必须使用反相后新测量上下文，不得恢复反相前缓存或把旧横线再翻一次；源反相、显示反相与逻辑极性归一化仍只能各按其声明作用一次。
- 读数浮窗可以继续显示 A/B 光标处多个相关通道值。
- 示意点不能复用这个多通道读数列表。
- 短路模式不自动绘制“短路开始”“短路结束”两根虚拟参考线；Tsc 起止位置只通过 A/B 主光标表达。

## 横向光标与本地平台

- `dv/dt`/`di/dt` 斜率卡必须显示两块职责分离的差值浮窗：左侧原位置的横向光标浮窗显示完整 `|Ha-Hb|` 与 `|Ha-Hb|/|B-A|`；顶部 `Δt / 1/Δt` 浮窗旁另放参数范围浮窗，显示实际百分比 A/B 交点的 `|Y(B)-Y(A)|` 与参数斜率。两块浮窗必须同时保留并随 Ha/Hb 手调重算，不能用其中一块替代、覆盖或隐藏另一块。
- 六个 `dv/dt`/`di/dt` 取值范围窗口都必须提供“自动最大斜率”，同时保留既有预设、自定义选项和默认值。自动模式在既有主沿内滑动固定 `20%` 幅值窗口并选择平均斜率最大者；它与固定位置的普通百分比预设不同。参数表范围列只显示本次实际起止百分比，例如 `46%→66%`，不得附加会撑宽侧栏的自动前缀或时间；百分比必须使用完整单元格并与普通预设保持相同的水平、垂直居中位置，不得为角标预留上方正文带而导致正文上移。自动身份用独立绘制的红色角标表达：左下“自”、右下“动”，颜色为高对比红 `#ff3b30`；默认 8px，角标实际包围框接近正文 1px 保护区时缩到 7px。角标不参与列宽计算、不得遮挡主体，也不得缩小到不可辨识；绘制角标时须排除正文保护区作为兜底。百分比正文必须只绘制一次，禁止默认委托与自定义委托重复绘制。内部结果、状态栏和报告仍可保留 `自动 46%→66%（14.2 ns）` 的完整诊断文本。
- 上述六项取值范围使用应用设置分别记忆最后选择，换文件和重启后继续生效。固定预设与自定义范围保存完整百分比及其物理语义；自动项只保存 `auto_max` 模式身份，当前单元格显示的实际百分比属于当前波形计算结果，严禁作为下一个文件的设置复用。首次运行、设置键缺失或某一项记录无效时，该项按 `default_slope_ranges()` 回退，其余有效记忆不受影响。测试必须使用隔离设置文件，不能向用户真实 QSettings 写入测试预设。
- 自动模式中的 A/B 仍是原始波形与自动所得百分比电平的锁定真实交点，交互规则与其他斜率范围一致：A/B 不可独立拖动，只允许调整 Ha/Hb；调整后由同一测量上下文重新选择自动区间，并同步表格、状态栏、顶部参数范围浮窗和报告范围文本。左侧完整 `|Ha-Hb|` 浮窗不因自动模式改变职责。
- 横向 `Ha/Hb`、`Top/Base` 或 10/90 参考线必须来自当前参数定义的本地窗口，或偏移测量行声明的 `full/screen/cursor` 范围。
- 用户局部放大后查看屏幕测量时，横向 base/top 值必须使用当前可见窗口，不得使用全波形、整段脉冲、旧参数缓存或 A/B 单点采样值。
- 真人目视验收横向平台线时，应在当前参数的稳定平台段内观察可见波形带的最大值与最小值，并以两者中点作为“是否卡在稳定带正中”的首要判断；窄毛刺或孤立过冲不得把平台中心拉到带边。实现仍须复用项目既有本地 `scope_top_base()`/稳定带中心口径，不能为单个截图改写计算公式。
- 默认开通 `dv/dt` 明确绑定原始逻辑本管 `Vce`，`Ha/Top=主下降沿前事件本地稳定高电压平台中心`、`Hb/Base=主下降后稳定低电压平台中心`，A/B 为 `90%→10%` 原始下降交点；默认反向恢复 `dv/dt` 明确绑定原始逻辑 `abs(对管Vd)`，`Ha/Top=恢复过冲后的事件本地稳定阻断平台中心`、`Hb/Base=主上升前稳定低电压平台中心`，A/B 为 `10%→90%` 原始上升交点。两项都必须直接显示 pipeline 的同一 `DvdtMeasurementContext`，不得按当前屏幕或高亮曲线重算；四条平台线都必须按上一条稳定平台中点规则目视验收。
- 开通 `dv/dt`、`di/dt` 和 `Ls_on` 的局部视窗同时服务 Base/Top 稳定电压或电流平台、或同一 Ic 积分窗观察：当前候选实现是在真实 A/B 和完整波形边界允许时，按真实 A/B 中点约 `43%` 的平衡比例构图，取消通用右优先的 `30%/70%` 平移。`Ls_on` 与开通 `di/dt` 共用真实 Ic A/B 积分端点，因此沿用同一比例。该比例借用既有 Tf/开通电流构图，并非从本轮失效的手调截图测出；最终视觉比例待补图确认。这只是 X 轴取景比例，不是固定时间，也不移动 A/B、Ha/Hb 或改变斜率、积分值。窗口仍优先保持 `200ns/div × 10 = 2us`，只有硬性必要时刻装不下才扩档。
- 默认 Trr 明确绑定原始带符号 `LOGIC_IRR`：Hb 在有符号 `I_RM` 峰值，Ha 直接位于参数本地峰后稳定窗的 max/min 平均中线，A/B 为主瓣两侧与 Ha 的首个原始交点。参数表、默认卡尺、状态栏和报告必须显示同一个默认上下文；没有常驻可见 Math 时也禁止回退到首个可见 CH。
- 默认关断 `ΔVce` 的四根光标必须分工显示：竖向 A 位于 Vce 抬升前的 Base 稳定段，竖向 B 位于尖峰后的 Top 稳定段并使 A/尖峰/B 时间有序；横向 Ha 位于 Vce 尖峰最大值，横向 Hb 位于稳定 Top 平台。A/B 表示参数所覆盖的物理阶段，不能再与 Ha/Hb 强制绑定成两个波形交点；手动调整时四根光标仍按非斜率规则独立保存。

- 参数局部窗口必须完全落在当前波形的完整可观察时间范围内，并保证该参数现有 A/B、对应电压/电流稳定平台区间，以及能辨认主参数物理过程的必要前后态可见；不得为了显示辅助 Vge 或保留过多平直段而牺牲实际 A/B、稳定平台或主沿。非门极参数默认优先保持约 `200ns/div × 10 = 2us`，`Ic_off_max` 单独使用参数级 `250ns/div × 10 = 2.5us` 软基准，以便让其事后 Base 稳定带和振荡收敛拥有与人工图二相近的观察比例；这个 `2.5us` 不是全局基准、硬性最小宽度或固定窗口。除 `Tf`、`开通/开通电流`、开通 `dv/dt`/`di/dt` 及 `Ls_on` 外，求解时先用硬性 `required`/A/B 包络占据必要宽度，再将同档位剩余余量约按左侧 `30%`、右侧 `70%` 分配，使左侧只保留足以辨认事前稳定平台的动态上下文，并把更多区域留给主事件后的振荡收敛和稳定平台复核；在不裁剪任何硬性内容且不扩档即可做到时，最晚的 `required` 必要时刻应不晚于窗口约 `50%`。`Tf` 是 `Toff=Td_off+Tf` 的末段：完整波形边界和 A/B 硬包络允许时，以真实 A/B 中点位于窗口约 `43%` 为首选，使 A/B 不因区间窄而贴在左侧，同时让 B 不晚于中线并保留更多右侧观察区。`开通/开通电流` 的 A/B 覆盖 Ic 基线到导通平台，若继续套用通用右优先规则会把 A 推到左边缘；在完整波形边界和硬包络允许时，同样以真实 A/B 中点位于窗口约 `43%` 为首选，让两根光标回到可读的中左区域并保留右侧平台观察区。开通 `dv/dt`/`di/dt` 也暂用真实 A/B 中点约 `43%` 以平衡前后稳定平台观察区；`Ls_on` 与开通 `di/dt` 共用真实 Ic A/B 积分窗，也暂用同一比例以避免积分窗贴近左侧。上述开通斜率与 `Ls_on` 比例仍待补回手调截图目视确认。这里的 `43%` 都是构图比例偏好，不是固定时间或移动 A/B 的依据。上述 `30%/70%`、`50%` 和 `43%` 都是无冲突时的构图偏好，不是固定 A/B 比例、固定左侧时长或扩档理由；`0.4us` 仍只是一张点名波形的观察示例。只有硬性 `required`/A/B 包络连同必要边缘保护本身装不进对应软基准时才允许向上扩水平档位；靠近完整波形边界或与硬性内容冲突时，必须优先保证全部必要时刻可见，并允许放宽余量比例和最晚点位置，不能因四舍五入缩窄或为追求比例裁掉稳定平台。
- 第一次点击参数必须按该参数的默认局部视窗策略构图；之后每个参数分别拥有自己的局部 X 轴页面。用户在主图或总览图中水平平移/调整窗口后，重复点击该参数，或先切换到其他参数查看再切回来，都必须恢复这个参数最后保存的精确窗口，不得重新套用默认锚点，也不得把其他参数的窗口串用过来。初始化默认区间和单纯平移视窗都不得伪造“用户手动光标区间”缓存；首击仍不得出现 `400ns/div`、二击才恢复 `200ns/div` 的差异。

## 手动光标值与报告一致性

- 用户真实拖动形成的手动光标状态是当前参数结果的一部分，不只是波形绘制缓存。只要当前波形源、测试模式和双脉冲 `off/on` 脉冲对没有改变，任何 `reset_manual=False` 的重新提取都必须把仍有效手动缓存拥有的参数值重新物化到新的 `ExtractResult`；表格、顶部摘要、报告准备快照和 Excel 写入必须读取同一份已物化结果。
- 点击“写入报告”时必须一次性冻结当前文件、测试模式、当前 `off/on` 脉冲对、已经物化人工参数值的 `ExtractResult`，以及每张参数卡各自的 A/B、Ha/Hb（适用时含 H0）和精确局部 X 轴页面。Excel 数值与报告截图必须消费这份同一时刻的不可变快照；后台准备、逐参数截图、页面恢复和最终 writer 均不得重新加载默认结果、重建默认光标或用 live UI 覆盖快照。
- 当前页面选中的脉冲对始终以这份冻结的人工校准结果覆盖默认自动结果；多脉冲报告只有其他未手调组合允许从同一 bundle/profile/cfg 快照后台重提取。截图回放 A/B、Ha/Hb 和局部视图只负责复现冻结画面，不能作为事后修正 Excel 默认数值的补救步骤。
- 报告请求若发现人工状态所有者与当前文件、测试模式或 `off/on` 脉冲对不一致，必须拒绝写入并报告状态失配；禁止静默丢弃人工状态后退回默认值，也禁止把另一文件或另一脉冲对的人工值写入当前报告。
- 手动值恢复必须按缓存所有权逐项执行：只恢复确实存在且仍有效的手动参数，未手调字段继续采用本次重新提取的新自动结果。`di/dt` 的数值、`unavailable_metrics` 和依赖它的 `Ls_on/Ls_off` 可用性必须作为同一状态恢复，禁止出现表格有旧数值而报告为空、或报告有数值而界面显示不可用。
- 手动状态的有效边界至少包含波形源、测试模式和当前 `off/on` 脉冲对。脉冲对发生变化时必须清空旧手动状态并使用新脉冲对的自动结果；之后再切回原脉冲对也不得把旧值复活。显式 `reset_manual=True`、载入新波形或模式切换继续按既有规则清空。
- 参数定义本身变化时，只失效受影响的手动状态：修改某一 `dv/dt` 或 `di/dt` 范围要清除该项斜率及依赖它的 Ls 手动区间，但不得清除无关的 Eon/Eoff 等手调值；修改短路 Tsc 取值范围要同时清除旧 Tsc 区间和完整短路 Tsc 光标缓存。
- 短路 Imax/Tsc 等参数恢复时必须保存该参数实际允许移动的全部光标状态。自动锁定的峰值光标继续由自动峰值定义控制，不能因为保存手动上下文而伪造成可移动或被旧值覆盖。

## 后台任务进度

- 右上角进度条是通用后台任务进度，不应只服务于报告写入。
- 原始数据导入必须能显示“读取原始数据、解析波形数据、识别通道、执行参数计算、刷新界面、绘制波形、导入完成/失败”等阶段。
- 报告写入必须能显示“复制模板、准备/执行截图、写入 Excel、保存报告文件、写入完成/失败”等阶段。
- 进度比例要贴近用户实际等待时间；截图和写入/保存不能长期挤在最后几个百分点里。
- 数据导入的阶段 ETA 只能由同一阶段已经真实完成的同质工作单元估算；至少得到两个独立完成间隔且速度稳定后才显示。一次批量回调即使完成多个单位，也只能贡献一个独立观测，不能拆成多个伪样本。不得用总耗时除硬编码百分比制造假精确 ETA。
- 报告写入使用整任务分阶段历史模型：复制模板、数据准备、截图、打开工作簿、写数据、插图、整理版式和保存分别记录成功样本耗时；按报告是否已存在、任务开始时文件大小、图片数、结果行数及本会话首次/后续写入选择最近同类样本，并用稳健中位数和保守先验预测。首次没有历史时也使用经真实报告验证的保守阶段预算，从任务开始即显示整任务“预计剩余”；本轮逐张截图/插图进度继续用于校正当前阶段。只有成功报告才允许写入本机历史，失败或损坏的持久记录必须忽略。
- TSS 数据导入中，只有 ZIP 内逐个 `.wfm` 成员完成读取/解析的同质阶段可以按已完成 WFM 数提供 ETA；至少两个独立成员完成前仍显示“估算中”。通道映射/趋势识别、脉冲分段与参数提取、结果应用和主界面绘制仍按原子阶段处理并显示“估算中”，不得把 WFM 阶段速率跨阶段外推。
- 运行中的正 ETA 小于 `1s` 时，用户界面统一显示 `<1 s>`，避免毫秒级假精度；内部时长格式化仍不得把任何正预测舍入为 `0ms`。`0ms` 只允许出现在成功的 `100%` 终态。
- 每个可见任务从 `1%` 开始。数据导入按真实检查点/同质单元推进；报告写入把 `1%~99.9%` 按预测阶段耗时比例分配，并在原子阶段内按已耗阶段预算平滑推进，但必须在下一个真实阶段检查点前封顶，不能把时间插值冒充阶段完成。归一化百分比必须严格单调，所有运行态最多显示 `99.9%`。失败时保留最后进度并取消 ETA；只有报告保存或导入界面应用成功返回后才能到 `100%/0ms`。首个成功/失败终态一旦产生即不可改写，终态后的迟到进度、重复完成或矛盾失败信号一律忽略。
- 任务进度栏必须随自身实际可用宽度响应式收缩，非最大化窗口不得出现阶段、详情、百分比、ETA 说明或 ETA 数值互相覆盖。宽度不足时按“移除分隔符 → 缩短 ETA 标题为‘剩余’ → 隐藏详情 → 极窄时隐藏 ETA 标题”的顺序降级；进度轨道、百分比和 ETA 数值始终保留，完整语义继续由工具提示提供。窗口重新放大后必须恢复完整标题和详情。
- 报告写入不再使用 `55%/57.5%/60%/80%/85%` 固定权重或“已耗时÷当前百分比”线性外推。各阶段显示区间由本次预测预算占整任务预算的比例动态生成；原子阶段超出预算时 ETA 仍保持正值并接受后续真实检查点校正。保存阶段可以在 `85%` 以上继续平滑前进，但必须封顶于 `99.9%`，仅在 `wb.save()` 成功返回后到 `100%/0ms`。
- 需要在 UI 线程执行的截图、绘图、控件抓取等步骤，应拆成可让事件循环刷新的小步骤，避免一次性长循环造成界面假死。
- 报告逐参数截图期间只允许像人工点击参数一样改变波形 ViewBox；严禁通过 `setFixedSize`、最小/最大尺寸或 SizePolicy 改写来重排波形控件或主窗口，主窗口和波形根控件的几何尺寸不得随截图变化。
- 报告截图结束恢复原页面时，必须先恢复原 ViewBox，再按恢复后的全景/局部范围同步总览图与水平标度栏的显隐，立即使波形面板布局失效并重新激活；进入 Excel 写入前至少留出一轮 Qt 事件循环，使隐藏控件的固定高度真正释放。原页面为全景时主波形必须重新占满波形面板，不能残留总览图 `86px`、水平标度栏 `20px` 及间距对应的顶部空白；原页面为局部视图时则必须恢复带有效曲线的总览图和标度栏。
- 报告 PNG 固定输出为 `1280×960` 物理像素时，应抓取当前完整 WaveformPlot 后在内存中等比缩放并居中补边；高 DPI 抓图必须先归一设备像素比，避免 `125%/150%` 缩放下内容二次缩小或偏心。PNG 保存失败、文件缺失或空文件必须中止报告写入，不能静默插入缺图。
- 报告新增波形块需要插入行时，必须同步移动已存在图片的 drawing anchor；相同 V/I 的陈旧 Rg/Cg 条件块可以清理，不同 V/I 的既有波形块不得因为合并后的组条件变化被误删，写入顺序也不得改变最终保留的波形块和图片数量。
- 波形条件标签不是文件路径，可以没有扩展名且 V/I 允许小数（例如 `900V_494.9A`、`850V_1061.01A`）；解析时不得把电流小数部分误当成文件扩展名剥离。截图清理是破坏性操作，只有明确解析出旧块 V/I，且能证明它是同条件重复块或没有数据行支撑的陈旧块时才允许执行；无法解析身份的旧版/自定义标签必须保留，不能把解析失败当作陈旧证据。
- 双脉冲与短路报告都以点击“写入报告”时的当前页面工况为权威。创建请求时必须同时冻结相位/上下桥代码、当前温度代码和 RT/HT/LT 三组显示数值，并沿数据准备、截图、Excel 写入完整传递；不得在后台末段重新从 live UI 或 `source_path` 覆盖用户选择。正常软件流程始终有页面快照，路径识别只负责加载时初始化页面；仅不启动窗口、直接调用底层 writer 的开发测试/维护脚本可兼容路径推断。`U_L` 中的 `L` 可能表示下桥臂，不能自动猜成 LT；显式温度只接受 RT/HT/LT，显式相位/桥臂只接受 UH/UL/VH/VL/WH/WL，非法值必须报错。
- RT/HT/LT 只表示页面温区分类和空模板种子，不是报告记录的唯一温度身份。报告数据行、波形块和截图清理必须使用实际温度值参与身份匹配；同一相位/桥臂、V/I 和门极条件下的 `150℃` 与 `170℃`、两个不同常温值或两个不同低温值都属于独立测试。已有实际温度不匹配时，双脉冲必须克隆新的四行数据组并保留独立波形块，短路必须克隆对应温度行组和图片块；不得重命名旧温度组后覆盖数据或删除旧图片。仅字面量 `RT/HT/LT` 的未初始化模板占位符可以在第一次写入时绑定为当前实际温度。
- 用户用 Microsoft Excel 打开、保存并退出报告后，程序必须仍能识别并继续写入既有 RT/HT/LT 实际温度身份。温度身份所有权不得只依赖 Excel 会在人工保存时删除的 defined-name `description`；必须另存 Excel 可稳定保留的隐藏 manifest。对修复前报告，只允许在 RT/HT/LT 三个隐藏、工作簿级保留名称完整存在且值均为合法温度时迁移；不完整、非隐藏、工作表级或值非法的同名集合仍须拒绝，不能为兼容而绕过防覆盖闸门。
- 多脉冲报告自动生成相邻有效组合时，当前页面选择的合法非相邻或同脉冲组合还必须去重加入；当前组合直接使用请求时冻结的结果，以保留用户手动调整，其他组合才允许基于同一份 bundle/profile/cfg 快照后台重提取。报告截图、波形条件标题与图片锚点必须绑定当前组合对应的数据行；插入新条件块时必须同步后移并保留已有波形块和图片。
- 进度条、状态栏和按钮禁用只属于交互反馈层，不能改变 TSS 解析结果、参数计算、损耗积分、光标落点、导出数据或报告模板结构。

## UI 与计算边界

- UI 显示层、拖动换算、标识刷新不能改变参数计算、积分窗口、斜率、时间窗和数值结果。
- 如果需要改变默认光标落点、横向平台线、Top/Base 或参考电平，必须按 `MEASUREMENT_SPEC.md`、`TEKTRONIX_MEASUREMENT_DEFINITIONS.md` 和 `REGRESSION_BASELINES.md` 的验证要求执行。
