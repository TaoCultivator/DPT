# 短路计算规范

本文用于固化短路模式的取值口径、默认光标落点、交互边界、导出/报告规则和回归验证要求。短路计算相关修复必须先完成本文规范确认，再进入代码实现。

## 制定状态

- 本文为短路计算、短路光标、短路数据区和短路报告写入的现行已确认规范。
- 已确认参数口径必须直接作为短路实现依据；不得继续保留与本文冲突的旧短路逻辑。
- 后续任何短路修复、优化或兼容性调整，都必须先补充到本文并经用户确认。
- 不得为了修复某个短路参数而顺手改动其他短路参数、DPT 参数、默认光标卡位、积分窗口或导出写入逻辑。
- 修改短路计算逻辑严禁改动双脉冲 DPT 计算逻辑；如短路实现必须触碰公共函数，必须先说明影响范围并获得用户同意。

## 需求边界

- 本规范只约束短路计算模式。
- 本规范不改变双脉冲 DPT 的 Eoff/Eon/Err/Trr、开通/关断斜率、串扰、功率或偏移测量口径。
- 短路修复不得改变双脉冲 DPT 的脉冲识别、通道映射、平台线、损耗窗口、Trr/Err、开通/关断参数、功率参数或默认光标卡位。
- 如果短路修复必须复用或改动公共函数，必须先说明会影响哪些非短路路径，并获得用户同意。
- 短路模式的 UI 显示层不得自行新增虚线、提示、联动或自动重算行为；如确实需要，必须先写入本文并获得用户确认。

## 通道角色定义

- 本管指本管 `Vge`、本管 `Vce`、`Ic`。
- 对管指对管 `Vge`、`V_二极管`、`Ic`。
- `Ic` 是本管和对管公用的电流通道。
- 通道映射必须为可选测项预留 `Vdesat` 指定接口，用于存在 `Vdesat` 波形时计算 `Desat` 动作时间。
- 本文后续所有“本管”“对管”参数都按上述角色关系理解；实际数据中的 CH/MATH 通道编号仍由导入识别或手动通道映射指定。
- 未指定 `Vdesat` 时，只影响 `Desat` 动作时间为空值，不得影响 `Imax`、`Tsc`、`Esc`、`Vpeak` 等其他短路参数。

## 已确认硬规则

- 修改短路逻辑时，双脉冲 DPT 计算逻辑是红线，不得作为短路兼容性修复的顺手改动范围。
- 短路模式不自动绘制“短路开始”“短路结束”两根虚拟参考线；Tsc 起止位置只通过 A/B 主光标表达。
- 短路时间 `Tsc` 的取值范围可配置，默认命名为 `0%-0%`。
- 短路时间 `Tsc` 的取值范围必须持久化记忆；用户不改动时，重启软件或重新加载文件后仍保持上次选择。
- `10%-10%` 取值范围以短路电流最大值作为计算基准，`Hb` 卡在最大值的 10% 位置，A/B 纵向光标卡在对应电流曲线与阈值的真实交点。
- 修改 `Tsc` 取值范围只改变短路时间的 A/B/Ha/Hb 光标和 `Tsc` 数值，不得联动缩窄短路能量 `Esc` 的积分窗口，不得影响 `Imax`、`Vpeak`、`Desat` 或其他短路参数。

## 已确认参数口径

### 短路电流 Imax

- `Hb` 横向光标取短路电流波形的 base 值。
- `A` 纵向光标卡在短路电流上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在短路电流下降沿与 `Hb` 横向光标的第一个真实交点。
- `Ha` 横向光标取 `A` 与 `B` 之间短路电流波形的最大值。
- 移动 `Hb` 横向光标时，`A` 与 `B` 必须跟随更新到电流波形与新 `Hb` 电平的上升沿/下降沿真实交点。
- `Imax` 的取值和默认光标只允许使用短路电流波形；不得因为计算 `Imax` 而联动修改 `Tsc`、`Esc`、`Vpeak`、`Desat` 或双脉冲 DPT 任意参数。
- 本条按用户当前表述固定为“最大值”口径；如果后续需要区分绝对值、带符号峰值或下桥特殊显示，必须再次写入本文并确认后才能实现。

### 短路时间 Tsc

- `Tsc` 有两套已确认取值逻辑，根据“范围取值”选项选择。
- 两套 `Tsc` 逻辑都只允许使用短路电流波形确定 A/B 光标位置。
- `Tsc` 数值等于 `A` 与 `B` 两根纵向光标之间的时间差。
- 切换 `Tsc` 范围只允许影响 `Tsc` 的 A/B/Ha/Hb 光标和 `Tsc` 数值，不得联动修改 `Imax`、`Esc`、`Vpeak`、`Desat` 或双脉冲 DPT 任意参数。

#### 0%-0%

- `Hb` 横向光标取短路电流波形的 base 值。
- `A` 纵向光标卡在短路电流上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在短路电流下降沿与 `Hb` 横向光标的第一个真实交点。
- `A` 与 `B` 之间的时间差就是短路时间 `Tsc`。

#### 10%-10%

- `Ha` 横向光标卡在短路电流最大值上，作为计算基准。
- `Hb` 横向光标卡在短路电流最大值的 10% 位置上。
- `A` 纵向光标卡在 `Hb` 横向光标与短路电流上升沿的第一个真实交点。
- `B` 纵向光标卡在 `Hb` 横向光标与短路电流下降沿的第一个真实交点。
- `A` 与 `B` 之间的时间差就是短路时间 `Tsc`。

### 短路能量 Esc_本管

- `Hb` 横向光标取短路电流波形的 base 值。
- `A` 纵向光标卡在短路电流上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在短路电流下降沿与 `Hb` 横向光标的第一个真实交点。
- `Esc_本管` 的数值按 `A` 与 `B` 之间电压波形乘以电流波形后对时间积分计算。
- `Ha` 横向光标取 `A` 与 `B` 之间积分结果的最大值。
- 如果已有计算通道显示能量曲线，`Ha` 横向光标取 `A` 与 `B` 之间该能量曲线的最大值。
- `Esc_本管` 的 A/B/Hb 光标只允许由短路电流波形确定；不得因为计算 `Esc_本管` 而改动双脉冲 DPT 损耗窗口或其他 DPT 参数光标。

### 短路能量 Esc_对管

- `Hb` 横向光标取短路电流波形的 base 值。
- `A` 纵向光标卡在短路电流上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在短路电流下降沿与 `Hb` 横向光标的第一个真实交点。
- `Esc_对管` 的数值按 `A` 与 `B` 之间对管 `V_二极管` 电压波形乘以公用 `Ic` 电流波形后对时间积分计算。
- `Ha` 横向光标取 `A` 与 `B` 之间积分结果的最大值。
- 如果已有计算通道显示能量曲线，`Ha` 横向光标取 `A` 与 `B` 之间该能量曲线的最大值。
- `Esc_对管` 的 A/B/Hb 光标只允许由短路电流波形确定；不得因为计算 `Esc_对管` 而改动双脉冲 DPT 损耗窗口或其他 DPT 参数光标。

### 应力电压 Vpeak_本管

- `Hb` 横向光标取栅极电压 `Vge` 波形的 base 值。
- `A` 纵向光标卡在 `Vge` 上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在 `Vge` 下降沿与 `Hb` 横向光标的第一个真实交点。
- `Vpeak_本管` 的数值取 `A` 与 `B` 之间 `Vce` 波形的最大值。
- `Ha` 横向光标卡在 `A` 与 `B` 之间 `Vce` 波形的最大值上。
- `Vpeak_本管` 的 A/B/Hb 光标只允许由 `Vge` 波形确定，`Ha` 只允许由 `Vce` 最大值确定；不得因为计算 `Vpeak_本管` 而改动双脉冲 DPT 任意参数光标。

### 应力电压 Vpeak_对管

- `Hb` 横向光标取本管栅极电压 `Vge` 波形的 base 值，不取对管 `Vge`。
- `A` 纵向光标卡在本管 `Vge` 上升沿与 `Hb` 横向光标的第一个真实交点。
- `B` 纵向光标卡在本管 `Vge` 下降沿与 `Hb` 横向光标的第一个真实交点。
- `Vpeak_对管` 的数值取 `A` 与 `B` 之间对管 `V_二极管` 波形的最大值。
- `Ha` 横向光标卡在 `A` 与 `B` 之间对管 `V_二极管` 波形的最大值上。
- `Vpeak_对管` 的 A/B/Hb 光标只允许由本管 `Vge` 波形确定，`Ha` 只允许由对管 `V_二极管` 最大值确定；不得因为计算 `Vpeak_对管` 而改动双脉冲 DPT 任意参数光标。

### Desat 动作时间

- `Desat` 动作时间不是每次必测项；当前示例文件没有 `Vdesat` 波形时，不得把缺失波形当成算法失败。
- 如果没有 `Vdesat` 通道，`Desat` 动作时间不计算、不估算。
- 没有 `Vdesat` 通道时，软件右侧参数数值显示 `-`，字体标红色；报告写入为空单元格。
- 如果示波器数据中存在 `Vdesat` 通道，`Desat` 动作时间按以下严格口径计算。
- `A` 纵向光标为短路导通起点，通常取本管 `Vge` 上升沿与 base 的第一个真实交点；如果已有已确认的短路开始点，则可按已确认的短路开始点。
- `B` 纵向光标卡在 `Vdesat` 上升到驱动器 DESAT 阈值的真实交点。
- `Desat` 动作时间为 `A` 与 `B` 之间的时间差。
- `Ha`/`Hb` 其中一条横向光标必须表示 `Vdesat` 判定阈值。
- 不得在缺少 `Vdesat` 通道时使用本管 `Vge`、本管 `Vce`、对管 `V_二极管`、`Ic` 或其他波形推算 `Desat` 动作时间。

### 数据区与报告写入

- 数据区中有有效测试参数输出时，报告写入该参数对应值。
- 参数未测试、缺少必要通道或按本文规则为空值时，报告对应数据单元格留空。
- 短路图片写入必须与实际测试参数对应；某参数没有测试或没有有效结果时，不截取、不写入该参数对应的短路图片内容。
- 例如没有 `Vdesat` 通道导致 `Desat` 动作时间为空时，报告中的 `Desat` 数据单元格留空，`Desat` 对应短路图片也留空。
- 不得为了填满报告而把未测试参数写成 `0`、复用其他参数截图，或截取与该参数无关的短路图片。

## 后续扩展需重新确认

以下内容不属于当前已确认实现范围，后续如要添加必须先补充本文并获得用户确认：

- 除 `0%-0%`、`10%-10%` 之外的新 `Tsc` 取值范围。
- `Desat` 驱动器阈值的具体默认数值；未配置阈值时仍按缺失处理。
- 短路模式之外的双脉冲 DPT 参数、光标、积分窗口或报告写入口径。

## 实施前置条件

短路计算修复开始前，必须满足：

- 本次修复涉及的短路取值口径已补齐并得到用户确认。
- 已列出本次改动只影响哪些短路参数。
- 已列出不会改动哪些非短路参数和已有 DPT 口径。
- 已确定验证样例、验证命令和失败时的回退策略。

## 验证要求

- 至少覆盖上桥与下桥短路样例。
- 至少覆盖 `0%-0%` 与 `10%-10%` 的 `Tsc` 取值范围。
- 切换 `Tsc` 取值范围时，必须验证 `Imax`、`Esc_本管`、`Esc_对管`、`Vpeak_本管`、`Vpeak_对管` 不被无关联动改变。
- 如果改动短路公共提取逻辑，必须跑全量 TSS 样例验证。
