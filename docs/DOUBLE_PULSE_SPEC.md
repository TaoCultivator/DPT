# 双脉冲计算规范

本文用于固化双脉冲 DPT 模式的脉冲识别、分段、参数取值、默认光标口径、导出边界和验证要求。短路计算与偏移测量有独立规范，不得把它们作为双脉冲兼容分支混入本文口径。

## 制定状态

- 本文为双脉冲计算逻辑的现行工程规范，依据当前实现整理。
- 代码实现入口主要为 `dpt_extractor/pipeline/run_extract.py`、`dpt_extractor/pipeline/extract.py`、`dpt_extractor/detect/pulse_detector.py`、`dpt_extractor/detect/segmenter.py` 和 `dpt_extractor/metrics/*.py`。
- 已确认的专业口径和回归样例仍以 `MEASUREMENT_SPEC.md`、`REGRESSION_BASELINES.md` 为共同约束；若数值快照需要重标定，必须单独修改回归基线并跑全量样例验证。
- 后续任何会影响双脉冲参数数值、默认光标、平台线、积分窗口、斜率窗口、Trr/Err 或导出写入的改动，都必须先补充本文或相关规范并获得用户确认。

## 需求边界

- 本规范只约束 `TestMode.DPT` 的双脉冲/单脉冲 DPT 参数提取。
- 本规范不改变短路模式的 `Imax/Tsc/Esc/Vpeak/Desat` 口径。
- 本规范不改变偏移测量的 `Maximum/Minimum/RMS/Area/Top/Base` 等示波器测量定义。
- 双脉冲修复不得顺手改动短路模式、偏移测量模式、报告模板结构、通道映射默认值或 UI 提示行为。
- 如果必须改公共函数，必须先说明会影响哪些非 DPT 路径，并获得用户同意。

## 模式入口与隔离

- `run_extraction()` 根据 `cfg.test_mode.mode` 调度：
  - `dpt` 进入 `extract_all()`。
  - `short_circuit` 进入 `extract_short_circuit()`。
  - `offset_measurement` 不执行参数提取，直接抛出“偏移测量模式不执行参数提取”。
- DPT 模式的输入由 `WaveformBundle` 和 `BridgeProfile` 共同确定：
  - `profile.vge`：本管门极电压。
  - `profile.vce`：本管 Vce。
  - `profile.v_diode`：对管/二极管电压，反向恢复相关参数需要。
  - `profile.vge_other`：对管门极电压，串扰参数需要。
  - 总电流由 `try_bundle_total_current()` 获取。
  - 反向恢复电流由 `try_bundle_reverse_recovery_current()` 获取。
- 上管通道映射必须按物理角色理解示波器 Label：标签标成下管/低侧 `Ic` 的通道（如 `IC_UL`、`IC_VL`、`IC_WL`、`IVL`、`IC_LOW`）是上管反向恢复支路电流 `Irr`，不是上管总电流 `Ic`；上管总电流应由 `Irr + IL` 得到。
- 下管通道映射中，标签标成同相下管/低侧 `Ic` 的通道才是本管总电流 `Ic`；下管 `Irr` 按 `Ic - IL` 得到。
- 当工况只有一个罗氏线圈且该唯一安培单位波形已直接测得本管总电流时，必须将该通道直接映射为 `Ic`，同时关闭 `Irr+IL` 和 `Ic-IL` 派生开关；不得因为缺少第二路电流而拒绝映射，也不得对直测总电流再做相加或相减。趋势识别应在示波器保存的主时基窗口内判断门极、两路 Vce 和该电流，避免长原始记录中的空白区吞掉有效脉冲。
- 若 TSS 电流探头保存为反相极性，软件只在逻辑电流层自动转正/转回物理方向，不修改原始通道数据；上管 `Irr` 的高电流平台应回到与 `IL` 相减的物理方向后再参与 `Irr + IL`。
- 缺少可选通道时，只把受影响参数加入 `unavailable_metrics`，不得让无关参数失败：
  - 缺反向恢复电流：`Irr/Trr/反向恢复 di/dt/Pdmax/Err` 不可用。
  - 缺对管电压：`Vrr/反向恢复 dv/dt/Pdmax/Err` 不可用。
  - 缺对管门极：关断和开通串扰不可用。

## 脉冲识别

### Vge 门极脉冲

- `PulseDetector.detect_all()` 对 `Vge` 做 `smooth_ns=40.0ns` 平滑。
- 正常占比波形取平滑后 `Vge` 的 2%/98% 分位作为低/高电平参考；当有效门极状态在长记录中占比过小、2%/98% 分位不能覆盖实际门极摆幅时，才允许用按 `min_pulse_width_us` 做持久化平滑后的低/高极值恢复参考电平，避免短有效段被全记录分位统计吞掉。
- 门极跨度小于 `1e-6` 时判定为无法识别门极脉冲。
- 滞回阈值：
  - `th_on = lo + hysteresis_ratio * span`，默认 `hysteresis_ratio=0.25`。
  - `th_off = lo + hysteresis_ratio * 0.5 * span`。
- 高电平区间宽度必须不小于 `min_pulse_width_us=0.3us`。
- T1、T2、T3、T4、T5 等连续高/低电平段只要实际时长 `>=0.5us`，必须保持为独立完整时间段：不得漏边沿、合并相邻脉冲或把多脉冲误判为单脉冲。`0.5us` 是必须兼容的最小工况单位，不是拒绝更短波形的硬阈值；更短高电平仍按现有 `0.3us` 有效脉宽配置处理。
- 最多保留前 `MAX_PULSES=10` 个有效脉冲。
- 如果直接识别不足两个脉冲，会尝试 `_fallback_wide_pulses()` 宽脉冲兜底。

### 脉冲选择

- 默认 `pulse_selection.off_pulse=1`、`pulse_selection.on_pulse=2`。
- 所有脉冲序号为 1-based。
- 双脉冲默认含义：
  - 关断取第 1 个门极脉冲的关断沿。
  - 开通和反向恢复取第 2 个门极脉冲的开通沿。
- 多脉冲允许选择后续脉冲，但 `on_pulse` 不能早于 `off_pulse`。
- 只识别到一个门极脉冲时进入单脉冲模式，只允许分析第 1 个脉冲的关断沿。

### 关断沿修正

- `PulseDetector._refine_pulse_off()` 在当前脉冲开通和粗略关断点/下一脉冲开通点之间搜索最后一个 `Vge 90% -> 10%` 下降穿越。
- 修正后的 `pulse1_off` 是 DPT 关断分段、关断 Vge 窗、关断时序和 Eoff 参考的核心锚点。

## 分段窗口

`Segmenter.build()` 输出 `SegmentIndices`：

- `turn_off=(off0, off1)`
- `turn_on=(on0, on1)`
- `reverse_recovery=(rr0, rr1)`
- `pulse1_on/pulse1_off/pulse2_on/pulse2_off`

### 关断段

- 关断段以 `pulse1_off` 为中心：
  - 前窗取 `max(turn_off_pre_ns, 0.05*p1_width)`，默认至少 `200ns`，上限 `3.0us`。
  - 后窗取 `max(turn_off_post_ns, 0.01*p1_width)`，默认至少 `500ns`，上限 `1.5us`。
- 慢栅或短脉冲工况下，`pulse1_off` 可能晚于真实 Vce 抬升；若 `Vce` 可用，必须用 `_turn_off_rise_start()` 从 `pulse1_off` 反向找关断主抬升脚，并在必要时把 `off0` 前移。
- `_turn_off_rise_start()` 必须反向搜索，避免把同一脉冲前端的开通暂态误当成关断抬升脚。

### 开通段

- 双脉冲开通段以 `pulse2_on` 为中心：
  - 前窗取 `max(turn_on_pre_ns, 0.05*gap12)`，默认至少 `100ns`，上限 `1.5us`。
  - 后窗取 `max(turn_on_post_ns, 0.12*max(p2_width,gap12))`，默认至少 `800ns`，上限 `2.5us`。
- 单脉冲模式没有有效开通段，只创建极短占位窗，开通和反向恢复结果保持默认空值。

### 反向恢复段

- 默认以开通段为搜索范围。
- 若 `Irr` 和 `Ic` 可用，`_reverse_recovery_window()` 在开通段内找反向恢复主峰：
  - 若正峰达到主幅值 10%，取正峰；否则取负峰。
  - 峰值小于 `5A` 时不缩窗，沿用开通段。
  - 起点向峰前找低于 `0.05*peak` 的位置，再向左留 `30ns` 裕量。
  - 终点向峰后最多 `400ns` 找低于 `0.1*peak` 的位置，再向右留 `30ns` 裕量；失败时使用约 `200ns` 兜底。

## 母线电压与工况电流

- `measure_vdc()` 优先使用 `cfg.vdc_override`。
- 无覆盖值时，优先在关断前窗口从 DUT Vce 和对管 Vce 中选择“高且平”的母线平台：
  - 平台候选中位电平必须高于 `_BUS_MIN_LEVEL=50V`。
  - `IQR / |median| <= _BUS_FLAT_RATIO=0.18` 视为足够平。
  - 多个候选满足时取更高者。
- 双脉冲中若脉冲间关断平台可用，会用该平台更新 `vdc_top` 和 `vdc`：
  - `vdc_top` 取接近示波器 Top 的高分位平台。
  - `vdc` 取平台中位口径。
- 当前 DPT 结果中的 `idc` 最终按用户定义使用 `turn_off.ic_off_max`。
- `vdc_set` 写入 `vdc_top`，`idc_set` 写入 `ic_off_max`。

## 参数局部取景（仅显示层）

- 非门极参数必须先完整容纳真实 A/B、本参数稳定平台和主事件，再把同一水平档位的剩余余量约按左 `30%`、右 `70%` 分配，优先保留主事件之后的振荡收敛与 Top/Base 复核空间；开通 `dv/dt`、`di/dt` 以及与开通 `di/dt` 共用真实 Ic A/B 积分端点的 `Ls_on`，在硬内容允许时采用真实 A/B 中点约 `43%` 的平衡构图，以同时观察 Base/Top 稳定电压或电流平台。该比例只是无冲突时的自适应构图偏好，不能反向改变提取、平台、积分窗、光标或参数值。
- 局部窗口通常以 `200ns/div × 10 = 2us` 为软基准；`Ic_off_max` 单项使用 `250ns/div × 10 = 2.5us` 参数级软基准。`2.5us` 不是全局基准或硬性最小宽度，左侧也不存在固定 `0.4us`：左侧前态必须由当前波形实际 A/B 与稳定带动态决定，只有硬内容装不下时才扩档。

## 关断参数

### 基础量

- `Vce_off_max`：关断段内 `Vce` 最大值。
- `Ic_off_max`：优先在第一脉冲 `Vge` 下降窗内取 `|Ic|` 最大值；若下降窗不可用，回退到关断段内 `|Ic|` 最大值。
- `Vce_off_max` 默认竖向 A/B 复用关断 Vce 的稳定 `Base→Top` 物理阶段；横向 `Ha` 固定为上述原始数值窗口内的权威最大值，`Hb` 为尖峰后稳定阻断 `Top`。扩大后的显示范围不得重新选峰或改写表格值。
- `Ic_off_max` 默认竖向 A 位于 Vce 抬升前 `Base` 稳定段的代表点；B 取同一次关断 Ic 主抬升前的稳定 `Base` 段（`di/dt` 上下文 `base_window`）内最接近该 Base 电平的代表点（2026-10-16 用户拍板「甲 · 稳定抬升前 Base」，与 accepted `turn-off-delta-vce-stable-range-cursors-v24` 一致；不得改为「Ic 主下降结束后向右搜索的首个完整 `200ns` 稳定带中心」）。横向 `Ha` 为原 Vge 下降窗内的权威 Ic 最大值，`Hb` 仍为提取层发布的带符号 Ic Base；B 的显示稳定带不得重新估计或覆盖 Hb。A/B 必须包含权威峰值，但不得用扩大后的 A/B 重算初始 Ha。
- `Delta Vce off`：`Vce_off_max - vce_off_top`。
- `vce_off_top` 应以可靠母线平台为基准，不得因关断前窗横跨切换沿而失真。
- 关断 `Delta Vce` 默认竖向光标用于表达参数的完整取值阶段：A 位于 Vce 主抬升前最后一段安静的 `Base` 稳定带，B 位于尖峰之后第一段安静的 `Top` 稳定带，并满足 `A < Vce尖峰 < B`。A 不得放在尖峰时刻，B 不得取上升沿或振铃中第一次碰到 Top 电平的交点。
- 关断 `Delta Vce` 默认横向光标独立取值：`Ha=Vce_off_max` 尖峰最大值，`Hb=vce_off_top` 稳定阻断平台；表格和报告数值仍严格使用 `abs(Ha-Hb)=Vce_off_max-vce_off_top`，不得因竖向范围调整而改写计算公式。
- 该卡属于非斜率独立光标模式。手动拖动 A/B 只改变竖向取值范围的展示与保存，不能带动 Ha/Hb；手动拖动 Ha/Hb 才按既有规则更新 `Delta Vce` 及其对 `Ls_off` 的幅值校准，不能反向吸附 A/B。

### 关断斜率

- 默认范围：
  - `dv/dt off`：`10% -> 90%`。
  - `di/dt off`：`90% -> 10%`，电流参考为本次关断窗最大电流，方向为下降。
- 关断、开通、反向恢复六个斜率项的可选“自动最大斜率”统一在各自既有主沿内滑动固定 `20%` 幅值窗口，并按 `20%/Δt` 选择平均斜率最大且通过连续、单调、线性与噪声门槛的区间。该选项不改变默认百分比范围、事件窗口、Top/Base、波形源或极性；最终 A/B 和数值仍按原始波形真实交点计算。
- `dv/dt off` 的 `Top` 取关断后本地高平台稳定带中心，`Base` 取关断参数窗口起点前约 `0.5~0.1us` 的本地低平台稳定带 `(max+min)/2`；孤立毛刺不计入稳定带边界。阈值统一按 `Base + pct * (Top - Base)`，并在同一关断参数上下文内查找 Vce 上升真实交点。
- `di/dt off` 的 `Top/Ha` 取 Vge 关断电流下降窗中主下降前的稳定高电流平台中心，`Base/Hb` 取主下降后本地稳定低电流平台中心；独立的 `Ic_off_max` 继续取该窗峰值，不得冒充 Top。阈值统一按 `Base + pct * (Top - Base)`，并在同一关断参数上下文内查找 `|Ic|` 下降真实交点。
- 关断 `Top/Base`、参考线、A/B、表格值、报告值必须由 pipeline 与 GUI 共用同一个纯测量上下文；表格/报告“范围取值”只显示百分比标签，详细 Top/Base 数值仅进入状态栏诊断。
- 百分比交点优先在 Vge 关断主沿窗口内查找；任一交点缺失时才允许把终点有限延伸到参数本地窗口末端，并且仅在同时取得有序真实 A/B 时采用扩窗结果。否则才允许回退到原主沿窗口内最大斜率，且不得把回退结果显示成完整 A/B 卡尺。
- 极慢 Vge 下降仍先走上述历史主窗；只有主窗中 `98%/95%/90%` 三个下降交点都不存在时，才向第一脉冲内部更早位置扩展 Vge 起点搜索。扩展不得跨脉冲，且已在主窗得到真实交点的普通样例不得改变。
- `Ls_off` 使用波形积分形式 `L = integral(uL dt) / abs(Delta Ic)`：`di/dt off` 的真实 A/B 交点只限定搜索边界；边界内取包含主尖峰的连续正过冲瓣，`uL=max(Vce-Vce blocking Top, 0)`，有效支撑门槛为 `max(0.5V, 5% * 主尖峰幅值)`，电压面积和电流变化必须使用该支撑瓣的同一时间端点。
- 自动 `Ls_off` 不得再用不同时刻的单点 `Delta Vce off / 平均 di/dt off` 代替同窗积分，也不得按电流点、温度或桥臂引入固定修正系数。
- `Ls_off` 参数卡的 A/B 显示实际同步积分窗并绑定逻辑 `Ic`；Ha/Hb 不适用。手动拖动 A/B 时，在用户给定的完整区间内重算 `integral(max(Vce-Top,0)dt) / abs(Delta Ic)`，不得改写 `Delta Vce` 或 `di/dt`。
- 手动调整关断 `Delta Vce` 时，`Ls_off` 必须同步变化：保持当前原始波形积分形状和 A/B 时间窗，以 `Delta Vce manual / Delta Vce automatic` 对电压面积作线性幅值校准。这里的“同窗”只禁止错配时间窗，不表示 `Ls_off` 与 `Delta Vce` 解耦。

### 关断时间

- `Td_off = 90%Vge下降穿越 -> 90%Ic下降穿越`。
- `Tf = 90%Ic下降穿越 -> 10%Ic下降穿越`。
- `Toff = 90%Vge下降穿越 -> 10%Ic下降穿越`。
- `Toff` 应等于 `Td_off + Tf` 的同一套交点口径。
- Vge 电平用下降窗估计，Ic 搜索窗允许延伸到 `pulse1_off` 后，避免漏掉电流拖尾。

### Eoff

- `Eoff` 必须使用 `eoff_energy_markers()` 的卡尺窗口。
- `Ha`：Vce 抬升前导通平台。
- `Hb`：Ic 回落后的本地平台，保持带符号；下桥回落为负时不得取绝对值。
- `eoff_energy_markers()` 必须显式发布端点模式。缺少该字段的旧上下文按 `level_crossings` 解释，不得猜测为稳定带模式。
- `stable_platforms` 只用于当前关断事件包络被判定为 smooth/无明显振荡，且前后稳定带均合格、候选 A/B 完整包含本次原始 `Vce*Ic` 主功率峰的情况。任一条件失败、波形为 damped/ringing 或无法证明 smooth 时，必须使用 `level_crossings` 既有路径；不得按文件名、工况电流、温度或桥臂硬分型。
- `stable_platforms` 的 `A` 取 Vce 主抬升前合格 Base 稳定带的代表时刻；`B` 取 Ic 主下降完成后从左到右的第一个合格 Base 稳定带代表时刻。A/B 不强制与 Ha/Hb 相交；Ha/Hb 仍是上述事件局部平台值，不得由 A/B 单点反算或重标定。
- `level_crossings` 保持现行 damped/ringing 交点/包络口径：`A` 是 Vce 持续主上升沿与 `Ha` 的真实插值交点，`B` 是 Ic 主下降后、本次事件包络首次达到低幅稳定标准时与 `Hb` 的真实插值交点。边沿拟合只定位主沿，发布的 A 仍须回插到原始 `Vce∩Ha`。
- 无论使用哪种端点模式，发布的 A/B 都必须有序、完整包含本次主功率峰，并同时作为原始 `Vce*Ic` 真实积分、Pmax、GUI 卡尺、参数表/顶部摘要、快照和报告写入的唯一时间窗。
- 稳定带搜索与代表点必须随采样率和当前波形自适应；不得写死 `0.4us`、固定 A/B 间隔或固定局部显示窗。
- 积分公式为原始 `Vce * Ic` 对时间积分，结果单位 mJ。
- `Pmax` 为同一积分窗口内 `Vce * Ic` 峰值，单位 KW。
- 可见 W/kW Math 只允许作为 `Pmax` 的卡尺显示源；进入、拖动、切卡后恢复或重新点击时，卡值仍必须从当前 A/B 窗内的原始 `Vce * Ic` 重算，不能被 Math 的显示缩放值覆写。
- 不得恢复“第一次刚碰平台”“固定尾窗”“段界点”“最后显著拖尾”等旧窗口。
- 本节只修改 smooth Eoff 的默认端点选择；Eon/Err 的交点、平台、积分和功率口径均不变。

### 关断串扰

- 若对管 `Vge` 可用，关断串扰显示关断段内对管 `Vge` 的 `max/min`。
- 默认竖向 A/B 不再直接铺满整段关断窗口，而是卡在该完整关断取值段内对管 `Vge` 达到 raw `max/min` 的两个时刻（按时间先后排序）；完整关断段仍是极值搜索包络，因此不能因收窄显示光标改变 `Vmax/Vmin`。横向 `Ha/Hb` 继续分别绑定同一取值段的最大/最小电平。手动拖动后才以用户新的 A/B 窗口重算串扰值。
- 默认搜索严格复用提取阶段的 `[off0, off1)` 原始索引，不得通过 µs 往返换算把右端样本混入；同一最大/最小值多次出现时选择相距最近的一对。恒定波形、单点或非有限数据没有可用极值对时保留原事件显示范围。首次点击与恢复手动卡片只显示已有结果，不能顺手重算；手动拖动仍在释放后提交。
- 缺少对管 `Vge` 时，只标记串扰不可用，不得影响其他关断参数。

## 开通参数

### 基础量

- 开通使用第二脉冲 `pulse2_on` 所在窗口。
- `Vce_on_max`：数值仍取既有开通事件数值窗内的 Vce 最大值。默认 A 放在该权威最大值左侧相邻的 `Top` 稳定段，B 放在 Vce 主下降之后首个完整 `200ns` 合格 `Base` 稳定带中心；B 必须排除下降尾段和未收敛振荡，且不能越过下一关断。先保证严格包含权威峰值及稳定证据，再尽量缩短两根竖向光标间距；最大值早于主下降沿时也不能为了窄窗丢弃。A 不由 Vge 抬升点拥有，该卡的独立默认时间上下文不改开通 `ΔVce` 的默认落点。横向 `Ha` 仍固定为既有数值窗的权威最大值，`Hb` 保留既有 Vce 稳定 Base，显示范围不得重新选峰或重估水平值。
- `Ic_on_max`：数值仍在“电流 base 抬升开始”到“Vce 下降到 base 附近”的既有区间内取 `|Ic|` 最大值。默认竖向 A/B 均绑定带符号 Ic：A 位于抬升前最近的 Base 稳定带，B 从电流峰值后向右寻找振荡收敛后的第一个合格 Top 稳定带，以稳定带代表点表达时间范围；不再使用 Vce 主下降后的 Base 作为 B。Top 电平参考窗与 B 的搜索范围分开，不能将参考窗起点或固定延时直接当作 B。横向 `Ha` 为既有数值窗权威最大值，`Hb` 保留既有带符号 Ic Base；本次竖向修正不得改写两条横线幅值、最大值搜索或手动/报告结果。
- `开通电流`：使用 `turn_on_current_hb_ha_t()`，以 Ic 抬升沿定位前后平台，取抬升后振荡结束平台 `Ha`；该值必须与开通 `di/dt` 的 `Ha` 口径保持一致。
- 默认开通电流光标的 `Hb` 取带符号逻辑 Ic 抬升前 `250ns~50ns` 完整原始稳定带经孤立单采样毛刺保护后的 `(max+min)/2`；保护范围同时包括稳定带首点和末点。多个稀疏单点互相污染全带阈值时，只迭代排除由立即邻点及两侧平台外延共同证实、且仍决定剩余带 `min/max` 的孤立极值；端点需连续第三个带内邻点证明平台延续，证据不足、真实斜坡、连续/阻尼振铃和多采样异常保留 raw。A 取该带起点至抬升后 `30ns` 内原始带符号 Ic 与 `Hb` 的最后一个上升插值交点。若 A 早于 `Vge10-detect_window`，把稳定带左边界裁到 `turn_on[0]` 后重算并再次校验，仍过早或无原始交点则 A 为 `NaN`。该光标规则不改变 `Ha`、B、pipeline、开通 `di/dt` 或 `Eon`。

### 开通斜率

- 默认范围：
  - `dv/dt on`：`90% -> 10%`。
  - `di/dt on`：`10% -> 90%`，电流参考为开通 `Ic Top`，方向为上升。
- `Vce Top` 以“总电流从近零开始抬升”的时刻为右端，向左取约 `200ns` 窗估计；这是 ΔVce/Ls 等既有参数的独立参考，不得反向覆盖 dv/dt 的稳定平台上下文。
- 默认 `dv/dt on` 必须绑定原始逻辑本管 `Vce`，由一个 `DvdtMeasurementContext` 同时提交表格值、GUI/报告卡尺和原始交点。`Ha/Top` 取本次开通 Vce 主下降沿前的事件本地稳定高电压平台中心，`Hb/Base` 取主下降沿后、下一关断事件前的稳定低电压平台中心；两者都不能取全段极值、孤立过冲或稳定带边缘分位数。
- `dv/dt on` 在完整开通段内按原始 `Vce` 下降依次查找 `90% -> 10%` 真实插值交点；阈值统一为 `Base + pct * (Top - Base)`。GUI 不得另取当前高亮通道、硬编码 0V 或 `Vce_on_max` 重建 Ha/Hb/A/B。
- 若完整开通段仍未包含慢速 Vce 回落的两个交点，只在该缺失情况下把搜索末端延长到 `pulse2_off`；沿用相同 Ha/Hb 和原始 Vce，并且仅在取得有序真实 `90%→10%` A/B 后提交。原段已完整时保持历史结果。
- `di/dt on` 在完整开通段内查找 `|Ic|` 上升穿越，阈值按 `pct * Ic Top`。
- 若百分比穿越失败，数值才允许按既有口径回退到窗口内最大斜率；没有完整有序原始交点时，GUI 不得伪造 A/B 卡尺。

### 开通 Delta Vce 与 Ls_on

- `Delta Vce on` 上点固定取开通 `Vce Top`。
- 默认竖向 A/B 只表达这项电压差发生的物理阶段：A 位于 Vce 主下降前的稳定 `Top`，B 位于主下降后的稳定 `Base`；不得为了把辅助 Vge 放进局部窗口而把 Vce 主下降和稳定平台挤到最右侧。默认横向 `Ha/Hb` 继续分别显示既有 `Vce Top` 与下述拐点/平台点，自动 `Delta Vce on` 数值不因 A/B 展示范围变化而重算。
- 下点由 `_turn_on_delta_vce_knee_point()` 自适应确定：
  - 若主下降前存在短稳定平台，优先取平台段 `(max+min)/2`。
  - 若存在三斜率下降形态，取两个高速段之间的中间段时间点；若中间段形成稳定平台，取平台 `(max+min)/2`。
  - 若为两斜率下降，取第一段平缓下降结束、第二段主下降开始的拐点。固定导数门槛若已在 `Vce Top` 的前 `20%` 压降内命中，保留该早期真实拐点；若门槛落入主下降深处，则分别拟合平缓预降段和主下降段，以两条局部趋势线的交点作为下点。拟合只允许使用当前事件窗、稳定 `Vce Top` 和波形形态，且交点必须贴近平滑后的真实边沿；不得按文件名、模块号、桥臂或温度写样本修正。
  - 特征不明显时，回退到第二次明显下降起点，再失败才取主下降最陡点。
- 不允许把下点改成全段最小值、Eon 损耗 B 点或导通后长尾振铃点。
- `Ls_on` 使用波形积分形式 `L = integral(uL dt) / abs(Delta Ic)`；默认 A/B 与开通 `di/dt` 的真实 Ic 百分比交点共用时间端点，`uL=max(Vce Top-Vce(t), 0)`，电压面积和电流变化必须来自同一 A/B 窗。
- 自动 `Ls_on` 不得再用 Vce 拐点单点 `Delta Vce on / 平均 di/dt on` 代替同窗积分；`Delta Vce on` 的拐点定义保持不变，并作为手动电压幅值校准量。
- `Ls_on` 参数卡的 A/B 绑定逻辑 `Ic`，Ha/Hb 不适用；手动拖动 A/B 只重算当前同窗电压面积和 `Delta Ic`，不得改写 `Delta Vce` 或 `di/dt`。
- 手动调整开通 `Delta Vce` 时，`Ls_on` 按 `Delta Vce manual / Delta Vce automatic` 对当前电压面积作线性幅值校准并实时更新；这等价于在 `U * n * Delta t = Delta I * L` 中校准电压幅值 U，同时保留原始波形随时间的形状因子。

### 开通时间

- `Td_on = 10%Vge上升穿越 -> 10%Ic上升穿越`。
- `Tr = 10%Ic上升穿越 -> 90%Ic上升穿越`。
- `Ton = 10%Vge上升穿越 -> 90%Ic上升穿越`。
- `Ton` 应等于 `Td_on + Tr` 的同一套交点口径。
- 默认优先保留第二脉冲开通点后约 `500ns` 的历史搜索窗，避免普通样例数值无依据漂移。
- 仅当历史搜索窗找不到完整且有序的 `10%Ic/90%Ic` 上升交点时，才允许用 `pulse2_on~pulse2_off` 内的稳定开通电流平台重新确定 `Ic Top`，并把交点搜索上限扩到 `pulse2_off`。只有 `t_i10 < t_i90` 且两点都有效时才能提交回退结果；不得用单点、倒序交点或段尾硬凑 `Td_on/Tr/Ton`。

### Eon

- `Eon` 必须使用 `eon_energy_markers()` 的卡尺窗口。
- `Ha`：Ic 抬升前低平台，保持带符号。
- `A`：Ic 主上升沿与 `Ha` 的真实插值交点。
- `Hb`：Vce 回落后的导通平台。
- `B`：Vce 经过主下降后、局部可见阻尼振荡首次达到低幅稳定标准时，与 `Hb` 的真实插值交点。
- 积分窗口必须与 A/B 光标一致。
- 积分公式为原始 `Vce * Ic` 对时间积分，结果单位 mJ。
- `Pmax` 为同一窗口内 `Vce * Ic` 峰值，单位 KW。
- 可见 W/kW Math 只负责 `Pmax/Eon` 的辅助显示；恢复手动窗口或重新进入任一卡时，`Pmax` 与 `Eon` 仍分别由原始 `Vce * Ic` 峰值和积分决定，Math 缩放不得写回结果对象、参数表或报告。
- 手动拖动竖向光标后的联动显示值不得反向重标定 `Hb(Vce)` 平台。

### 开通串扰

- 若对管 `Vge` 可用，开通串扰显示开通段内对管 `Vge` 的 `max/min`。
- 开通采用与关断完全相同的显示逻辑：默认竖向 A/B 卡在完整开通取值段内对管 `Vge` 达到 raw `max/min` 的两个时刻（按时间先后排序），横向 `Ha/Hb` 绑定同一段的最大/最小电平；A/B 收窄只改善观察，不改变开通串扰的自动取值。两种边沿必须共用同一实现，不能因上升/下降方向分叉。
- 开通同样严格使用 `[on0, on1)` 原始索引，并复用关断的最近等值极值对、退化数据回退和手动释放提交规则；切换参数及生成报告截图时不得重新计算默认值并覆盖手动结果。
- 缺少对管 `Vge` 时，只标记串扰不可用，不得影响其他开通参数。

## 反向恢复参数

### Irr

- `Irr` 由 `irr_parameter_peak_value()` 计算。
- 搜索从第二脉冲开通沿之后开始，限制在开通窗口内。
- 取反向恢复主瓣同极性峰值的幅值，结果为正数。
- 不得把开通前平台、后续换流尾巴或错误脉冲峰值作为 `Irr`。
- 默认竖向 A/B 表达完整恢复电流阶段：A 位于恢复主瓣前的带符号前向稳定平台，B 位于主瓣结束后的恢复 `Base` 稳定平台。默认横向 `Hb` 保留上述权威有符号 `I_RM` 峰值，`Ha` 显示恢复 `Base` 稳定平台；该 A/B 不得复用 Trr 的两个 `Irr=Ha` 交点。自动 `Irr` 数值仍来自既有峰值函数，默认展示范围不能重新选峰。
- A/B 默认落点分别选最近的完整前态稳定带与振荡后首个完整稳定带中心；低电流的真实噪声底需由本事件多个局部参考带估计，不能以一个异常安静块、某次穿越平台线或固定峰后延时替代稳定证据。事前电平提示须与原始 Irr 事前样本一致；拒绝错误提示不改变任何已有斜率/恢复参数数值。上升外观中的“Base→Top”与反相后的下降外观使用同一带符号规则，不能交换 A/B 或改写已有恢复 Base/峰值横线语义。

### Trr

- `Trr` 自动结果、默认光标、参数表和报告必须共用 `metrics/irr_measure.py::default_irr_trr_measure()` 返回的同一个 `IrrTrrMeasure`；GUI 或导出层不得重新推断峰值、恢复平台或交点。
- 默认口径由 `default_irr_trr_measure()` 给出：
  - 测量源是映射与人工通道反相均已按声明作用一次后的原始带符号逻辑 `Irr`；上管/下管角色继续服从既有 `Irr` 映射，不按目录、桥臂或当前高亮通道再次猜测极性。
  - `Hb` 是 `irr_parameter_peak_index()` 锁定的有符号 `I_RM` 主峰。
  - `stable_level` 是主峰后本次恢复事件的本地稳定平台中心，优先使用峰后 `300ns~600ns` 平台窗；短记录才使用可用短尾。最终值取孤立毛刺保护后稳定波形最大值与最小值的平均中线。
  - `Ha = stable_level`，直接卡在峰后恢复稳定平台本身的 `0.5*(max+min)` 中线上；不得再取恢复平台与峰值的 50% 半幅。
  - `A` 从本次反向恢复事件窗起点开始搜索，是逻辑 `Irr` 主瓣向峰值变化时与 `Ha` 的第一个原始插值交点；不得只回看峰前固定点数。
  - `B` 是主峰后主瓣回落到恢复平台时与同一 `Ha` 的第一个原始插值交点；若后续振铃再次穿越，只取峰后第一个下降交点。
  - 必须满足 `A < peak < B`；默认标记落在同一条 `LOGIC_IRR` 的两个真实 `Irr∩Ha` 上。
  - `Trr = B - A`，单位 ns。
  - `pulse2_off` 是第二脉冲关断事件第一个采样点，也是 Trr 的排他硬上界。初始 RR 窗可以为覆盖完整恢复主瓣而向后扩展，但 `I_RM` 峰搜索、恢复稳定平台、A/B 和扩展尾窗均不得读取 `pulse2_off` 及其后的样本。
  - 若 `pulse2_off` 早于有效恢复峰完成，或峰后到该边界前不足 3 个有限原始样本，整个自动 `IrrTrrMeasure` 必须返回不可用；不得跨关断取峰、平台或交点，也不得保留部分 Ha/Hb/A/B 伪装成有效 Trr。
- Trr 是非斜率手动卡：进入手动状态后 A/B/Ha/Hb 四根光标独立可移动、保存且互不吸附；手动结果只按当前 A/B 时间差更新。该交互规则不允许反向改写自动恢复平台上下文。
- 不得使用峰/平台 50% 半幅、固定 `5A` 或 `0A` 近零阈值，不得使用 `25%I_RM` 尾段拟合外推零点，也不得把 Err 所需尾段振荡纳入 Trr。
- 反向恢复 `di/dt` 的 `measure=if_irm` 所用 `50%IF→50%IRM` 是换流斜率的另一套阈值与交点，不能复用为 Trr 的恢复平台 Ha，也不能被 Trr 改动。

### Vrr 与反向恢复斜率

- `Vrr`：开通过程中对管/二极管电压 `Vd` 的最大值。
- `Vrr` 默认竖向 A/B 表达对管电压从稳定 `Base` 抬升、经过权威过冲最大值、进入过冲后稳定 `Top` 的完整阶段；A 位于主上升前 Base 稳定带，B 位于过冲后第一段合格 Top 稳定带。默认横向 `Ha` 保留既有 `Vrr` 权威峰值，`Hb` 显示稳定 Top；不得把斜率百分比交点、过冲点或当前屏幕最大值冒充 A/B 稳定平台。
  - A/B 使用相邻完整 `200ns` 稳定证据带中心，不能被已进入主沿的开通段起点截断；B 随真实振荡长度后移，不受固定峰后 `1.35us` 上限截断，但不跨下一次关断。后续反弹会否决暂时平静的候选，没有合格证据时不返回伪稳定上下文。复用恢复稳定带选择器仅影响显示时间，不扩展 Vrr 数值搜索窗或改变既有平台电平。
- 反向恢复 `dv/dt`：
  - 默认范围 `10% -> 90%`。
  - 默认源为原始逻辑对管 `Vd` 的 `abs(Vd)`；`Ha/Top` 统一取本次恢复过冲后的稳定阻断高电压平台中心，`Hb/Base` 取主上升沿前的事件本地稳定低电压平台中心。高平台在过冲后、`pulse2_off` 前的有界事件本地窗中选取约 `200ns` 安静稳定带，低平台取主上升前约 `0.4~0.1us` 的稳定带；两者均用孤立毛刺保护后的原始 `(max+min)/2` 定位，不得用 `rr_slope_window` 内 `max(abs(Vd))`、`Vrr`、后续振铃峰或硬编码 0V 替代。
  - 在同一斜率窗内对原始 `abs(Vd)` 按时间查找 `Base + pct*(Top-Base)` 的 `10% -> 90%` 真实插值交点。`DvdtMeasurementContext` 必须同时拥有 Ha/Hb、阈值、A/B、斜率和 fallback 状态，pipeline、GUI 和报告只能复用它，不能各自从 `Vrr`、显示 Math 或当前屏幕重建。
- 反向恢复 `di/dt`：
  - 默认范围 `90% -> 10%`。
  - 默认 `measure=idm`。原始带符号 GUI 语义为 `Ha=恢复尾本地稳定 Top/基准`、`Hb=换流前带符号 IDM Base 平台`。换流前先取同一事件邻接的宽候选区：整区稳定时保留整区孤立毛刺保护后的原始 `0.5*(max+min)`；仅当稳健跨度和中点位移同时证明右侧已混入换流沿时，才切到其中约 `200ns` 安静稳定子带。不能无条件缩窗，也不能用 P5/P95、均值、中位数或后续相反符号恢复峰代替最终平台值。恢复尾 Ha 继续按其独立安静带取原始中点。
  - 令 `p = sign(IDM - Base)`、`q(t) = p * (Irr(t) - Base)`；在归一化的 `q` 上按时间先找持续有效的 `90%`，再找 `10%`，并回插到原始带符号 `Irr` 得到真实 A/B。即使 negative-first 原始主沿看起来是上升，也必须保持 `tA < tB` 且结果为正的斜率幅值，不得交换 A/B。
  - `50%IF -> 50%IRM` 使用 `measure=if_irm`；原始显示为 `H0=本地零基准`、`Ha=带符号 IF`、`Hb=带符号 IRM`，在同一极性归一化坐标中按时间顺序查找两个真实插值交点。
  - pipeline、GUI 默认卡尺/顶部读数和报告共用同一个 `RrDidtMeasurementContext`；人工通道反相先作用到逻辑 `Irr`，上下文只做一次极性归一化。正负探头方向必须复用相同的恢复峰邻接稳定平台中点策略和幅值保护，同一事件数学镜像后的 A/B 与斜率应保持不变。
  - GUI 的 `ΔI` 和 `ΔI/Δt` 使用原始波形在实际 A/B 百分比交点处的差值，不能用 `Ha↔Hb` 的 100% 全跨度代替。
- 自定义范围只能改变对应斜率的阈值和显示范围，不得联动改变 `Irr/Trr/Err`。

### Err

- `Err` 必须使用 `err_energy_markers()` 的卡尺窗口。
- `Ha`：由 `_err_recovery_settled_base` 选择本次恢复过程中第一个合格无明显振铃稳定带，在该带的原始带符号 `Irr` 样本上取 `0.5 * (max + min)`。不是 `I_RM` 主峰、全波形 Top，也不是整个显示窗的 histogram Top；孤立毛刺由共享稳定带保护排除。
- 局部放大窗口以约 `200ns/div` 的参数观察窗口为显示软基准，覆盖本次反向恢复事件、`B(Vd-Hb)` 和主要恢复尾段。显示取景与 `parameter_local` 稳定带搜索分离，不得把内部搜索范围直接当作屏幕范围，也不得固定写死 `0.4us` 左留或 `2us` 统计窗。
- 稳定区由本次反向恢复右侧局部振荡收敛决定，用于锚定本地窗口和 A 搜索，不得恢复峰后固定 `400ns~800ns` 尾窗。
- A 的稳定锚点必须是主要反向恢复振荡结束后的第一个合格入口：低峰峰值、中心贴近本地平台，并且后续没有明显反弹。若更早入口的峰峰值明显高于后续同事件候选，则不能抢占；但也不得因为后面尾段更安静就改取最后尾巴。
- “合格”还要求后续至少 `180ns` 的可用观察窗内不存在显著不同且更稳定的后续平台；最多检查 `420ns`。若存在这种后续平台，早期短静区只能视为缓降过渡台阶，不能提前结束 Err。
- `A`：原始带符号逻辑 `Irr` 与稳定带原始中点 `Ha` 在稳定区入口附近的真实交点；不得因 Irr 主峰为正或 Ha 为正而切换到 `abs(Irr)`/`abs(Ha)` 求交。`abs(Irr)` 只允许用于能量、功率等幅值计算。
- 若 `I_RM=80A~130A` 且紧凑开通窗结束后的 `120ns` 内逻辑 `Irr` 峰峰值仍不小于 `max(35A, 35%I_RM)`，Err 的 A 搜索上界可在同一第二脉冲内向后扩展最多 `300ns`，但不得越过 `pulse2_off`；扩展分支不得再用正向软恢复的早期交点把 A 拉回未收敛振铃包。
- `Hb`：第二脉冲开通过程中、Vd 主上升沿前的本地 Base；当前实现取 B 前约 `35~155ns` 的事件局部安静带，并在原始带符号 Vd 上取 `0.5 * (max + min)`。不得把 B 后的阻断 Top、整屏 histogram 或主上升沿尾巴混入 Hb。
- `B`：同一段 `Vd` 主上升沿与 `Hb` 的真实交点；`B` 常早于 `A`。
- `B` 与 offset `Hb` 精修必须共同通过 Vd 主上升验收；只有原候选不满足时，才启用 `pulse2_on` 下界重算，不能把 `pulse2_on` 当作所有样本的无条件硬下界。
- 积分窗口取 `min(A,B)` 到 `max(A,B)`，但光标语义仍保持 A=Irr、B=Vd。
- 积分公式为 `abs(Vd) * abs(Irr)` 对时间积分，结果单位 mJ。
- `Pdmax` 为同一窗口内 `abs(Vd) * abs(Irr)` 峰值，单位 KW。
- 可见功率 Math 只允许显示 `Pdmax/Err` 的卡尺；恢复或重新点击后，`Pdmax` 与 `Err` 必须继续按原始 `abs(Vd) * abs(Irr)` 的峰值和积分写入，不能采用 Math 的显示缩放值。
- 不得使用全局 base、全波形 Top、B 后 Top、第一脉冲关断 base、主峰 peak、主峰前最后上穿点、拟合点、段界点或旧兼容分支。

## 单脉冲处理

- 只识别到一个门极脉冲时，`single_pulse_mode=True`。
- 单脉冲只计算关断参数。
- `turn_on` 和 `reverse_recovery` 保持默认空值，Eon/Err/Trr 等不作为失败处理。
- 单脉冲导出和展示不得为了填表而构造第二脉冲开通窗或反向恢复窗。

## 多脉冲导出

- `dpt_export_pulse_pairs(count)` 规则：
  - `count == 1`：返回 `(1,1)`。
  - `count == 2`：返回 `(1,2)`，保持传统双脉冲单行。
  - `count > 2`：滑动导出 `(1,2)、(2,3)、...、(count-1,count)`。
- 第一脉冲开通不导出。
- 多脉冲导出对当前页面选中的脉冲组合直接使用点击“写入报告”时冻结的人工校准 `ExtractResult`，其人工参数值必须覆盖默认自动值；同时冻结该组合每张参数卡的 A/B、Ha/Hb（适用时含 H0）和精确局部 X 轴页面。如果该组合是合法的非相邻组合或同脉冲组合，应去重加入相邻组合列表。其余未手调组合才允许复制同一请求的 bundle/profile/cfg 快照并重设 `pulse_selection.off_pulse/on_pulse` 后重新提取。报告截图、波形条件标题和图片锚点必须绑定当前组合对应的数据行，不得默认绑到第一行。
- 报告请求必须核对人工状态所有者与当前文件、测试模式及 `off/on` 脉冲对。任一不匹配时必须拒绝写入，不能静默丢弃人工值后回退默认结果，也不能把其他文件或脉冲对的人工状态带入当前报告。
- 报告数据组和波形块必须使用点击“写入报告”时冻结的当前页面相位/上下桥、温度工况和温度显示数值；正常软件流程始终有页面快照，原始路径只负责加载时初始化页面。仅不启动窗口、直接调用底层 writer 的开发测试/维护脚本可兼容路径推断。
- DPT 顶部报告工况为 `Vdc`、`Idc`、`Rg_on`、`Rg_off`、`Cg`；五项只参与报告工况身份和单元格写入，不参与参数计算。顶部温区选择、RT/HT/LT 三组实际温度及这五项工况只按上下桥分成两套持久化记忆：`UH/VH/WH` 共用上桥一套，`UL/VL/WL` 共用下桥一套。同一桥臂内切换 U/V/W 相不得切换或重置记忆。TSS 逐项识别并只覆盖识别成功的字段，未识别字段保留当前桥臂上次填写，示波器读取不清空；相别或桥臂没有明确识别结果时也必须沿用当前选择。点击“写入报告”时五项与页面工况一起冻结；未填写字段明确写空且不得阻塞报告。

### 导出规则

- Excel/报告写入必须使用点击时冻结、已经物化当前人工覆盖的同一套 `ExtractResult`；当前选中脉冲对不得重新计算一套导出专用默认数值。逐参数截图必须消费同一快照中的 A/B、Ha/Hb/H0 与局部 X 轴页面，不能通过回放默认卡尺生成与 Excel 数值不一致的图片。
- 缺失参数写空或显示缺失值，不得填 `0` 冒充有效结果。
- `Etotal` 只在 `Eoff/Eon/Err` 均有效且总和大于 0 时写入。

## 实施红线

- 双脉冲参数数值的计算千万别改；除非用户明确要求，否则只允许改展示层、交互层或样式。
- Eoff/Eon/Err 的 A/B 光标、积分窗口和表格数值必须使用同一个时间点口径。
- Trr 自动表格、默认卡尺和手动卡尺不得各算一套。
- 开通电流/开通 di/dt 的 `Ha` 必须一致。
- 单脉冲不得误判为双脉冲；双脉冲重点样例不得退化成单脉冲。
- 短路修复不得触碰双脉冲 DPT 计算逻辑。
- 偏移测量模式不得调用双脉冲参数提取。
